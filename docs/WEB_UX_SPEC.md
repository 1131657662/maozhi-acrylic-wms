# Web 端交互与页面规范（WEB_UX_SPEC）

> 本文档中的状态、类型、结果等库值仅作实现标识；界面显示必须按 docs/UX_STANDARDS.md 映射为中文。

## 2. 三层操作结构

| 层级 | 内容 | 规则 |
|---|---|---|
| 页头 | 唯一主操作 | 每页最多 1 个 primary |
| 表格工具栏 | 导出、打印（占位）、列设置、刷新、筛选 | 与批量栏同高同位 |
| 行内 | 状态主操作 + 打印 + 「更多 ▾」 | 最多 3 个可见入口 |
| 选中后 | 批量栏替换工具栏 | 已选 N｜批量导出｜批量打印｜批量撤销｜取消 |

单号列为蓝色链接进详情，行内不再放「查看」。危险动作一律进「更多」并二次确认。

## 3. 行内操作按状态驱动

入库：待确认=确认入账；已入账=打印+更多（撤销/更正/导出/流水）；历史=打印+更多；终态=更多。
出库：计划中=编辑+打印；待确认=确认出库；部分发货=继续发货+打印；已出库=打印+更多；历史=打印+更多。

## 4. 选择与批量

1. 提示条与工具栏同高同位，勾选前后表格零位移；
2. 行选中只用浅背景，不加边框、不位移；
3. 复选框点击不触发打开详情；
4. 批量栏切换不改变表格位置；
5. 批量撤销需二次确认并列出受影响单号。

2026-11-10 补充：所有行均可勾选用于导出，不以撤销资格禁用复选框。批量撤销单独计算可撤子集，显示可撤/不可撤数量；历史导入、未入账及终态以中文说明原因，确认弹窗列出排除单号与原因；全部不可撤时禁用撤销并说明。导出仍包含全部选中记录。

排序按升序→降序→取消循环；取消恢复默认创建时间倒序并移除 URL 的 sortBy/direction，翻页不重新写入显式排序，表头不显示活动箭头。出库状态及入库原始/入账状态不提供表头排序；单号、往来、仓库、车牌、时间、包数、吨数保留服务端排序。

## 5. 详情多入口

单号链接、整行双击、行焦点 Enter 为三个必备入口，右键菜单可选。复选框只负责选择；不增加行内「查看」或第四个按钮。

## 6. 查询

### 6.1 快捷行（每页最多 3 项）

| 页面 | 快捷条件 |
|---|---|
| 入库 | 登记时间、单号 |
| 出库 | 建单时间、车牌号、客户 |
| 库存 | 仓库、商品 |
| 日志 | 时间、类型 |

日期默认不过滤；提供今天/昨天/本周/本月快捷。车牌、客户支持联想。

### 6.2 高级筛选抽屉

- 右侧滑出，420–480px，分组：单据 / 商品 / 往来 / 其他；
- 「筛选」显示激活数；条件以 tag 回显；全部进 URL；
- 支持保存为视图（条件 + 排序 + 列设置）。

### 6.3 商品反查

- 一个输入框模糊匹配编码/型号/品名，支持多选与任一/全部；
- 命中时行内追加「命中：编码/名称 · N 包 · X 吨」；
- 展开只显示命中明细；
- 分页按主单，禁止先 join 明细再分页；
- 结果标题显示「N 单 · M 行」；导出支持只导命中行。

实现使用现有inbound_lines、outbound_lines与master_products（现有型号source_model；B6a快照迁移后用快照字段）。先对命中集合做EXISTS或按单据分组，再按主单分页，响应matchedLineCount与matchedLines。多商品任一=至少命中一种，全部=每个所选商品均命中，重复选择去重；关键词匹配编码/型号/品名。不能照抄不存在的表/字段或假设(code,model,name)复合索引能加速所有包含查询；索引须按实际SQL/EXPLAIN与基准定。

## 7. 详情页

页头（单号+状态）→ 摘要 → 明细 → 生命周期/审计；底部固定操作条承载唯一主操作，不在页头再重复primary。危险动作收进底部「更多」并二次确认；更正入口只在列表「更多」与详情底部操作条。业务条件不满足的操作原则上隐藏；打印待接入/未配置占位是明确例外（disabled + tooltip）。更正临时冲突可禁用并显示中文原因，不增加行内第四入口。

## 8. 打印与导出

打印统一积木报表（延后），位置为行内可见位、详情操作条；未接入时disabled + tooltip「待接入积木报表」，接入后无配置时提示「未配置打印模板」。行内至多状态动作+打印+更多，细节见PRINT_SPEC。
导出：CSV/XLSX，详情页补「导出本单」。Web 导出同批实现 CSV 与 XLSX，但验收目标以 XLSX 为准，CSV 不作为本批验收门槛。

## 9. 视觉与密度

### 9.1 列宽与列设置

所有列（含默认隐藏与 hideInTable 列）都有数值宽度，缺省 120px；用户宽度按列 key 保存，范围 80–600px。表格固定布局，scroll.x 为当前可见列宽度之和加选择列 48px；拉宽一列只增大该列和表格总宽，容器及其他列不变。商品反查展开按钮并入命中摘要列，不另占未计宽度的列。

表头右侧 8px pointer 手柄支持固定列，拖动时锁住横向滚动；双击恢复该列默认宽度，无横向滚动时不显示手柄。显示/隐藏列立即重算总宽，重排时宽度跟随 key。刷新保持宽度/显隐/顺序；「重置列宽」恢复全部列（含隐藏列）宽度，「重置列设置」恢复全部默认设置。颜色使用 theme token，不新增拖拽依赖。

- 卡片圆角 12px、极浅阴影；无渐变/发光/入场动画；
- 行高 40px，行内操作可点高度 ≥32px；
- 数字等宽、右对齐；
- 页面不得整体横向溢出，仅表格内部滚动。

## 10. 验收

1. 勾选前后表格位移 0px（实测）；
2. 三种必备详情入口逐个可用；若实现右键菜单一并验证，行内无查看按钮；
3. 批量栏切换不改变表格位置；
4. 商品反查：单数、命中行数、摘要合计三者一致；
5. 1440/1280 无页面横向滚动；
6. 每页最多 1 个主按钮。

## 11. 公共契约与兼容（C16）

本文件唯一负责查询抽屉、选择/批量栏、详情入口、保存视图及导出公共行为；各页面只增加业务筛选与字段，不能另定一套参数或动作。

- 保留现有GET契约的fromDay/toDay、movement、sortBy、items、viewToken与rowToken；新增productCodes/productMode=any|all、matchedLines/Count等字段采用可选扩展，未知参数严格校验。未实现CSV/商品反查/单张导出/批量写不得当作已有能力；旧PDA/小程序契约不改名。
- 主单summary按去重主单，命中明细汇总仅算匹配行；「N单·M行」分别返回，不把命中行包吨误作整单合计。导出明确document_summary与matched_lines两种schema，命中行带原单号/行号；同一viewToken绑定条件/排序/粒度/数据水位，三范围（全部筛选/本页/选中）复用，过期409保留筛选，不提供半文件。
- CSV、单张导出及行粒度流式导出需要新增服务能力；CSV/XLSX均需单元格公式注入防护。列表与导出业务文案一致，审计原始JSON只限详情原始数据区。
- 批量撤销是本批唯一批量生命周期操作，操作名固定为 `reverse`；`void` 保持单据级接口与单据级确认，不扩展为批量作废。批量撤销按逐单事务执行，确认页列每单有效量、原因、版本token；每单独立幂等键，返回逐单成功/失败及中文原因。允许部分成功但明确展示，不宣称整批原子；未选中合法范围、历史/legacy-open、已冻结未入账等不允许项直接拒绝。重试只重放同正文或重试失败项，不重复补偿已成功单。
- 保存视图本阶段用浏览器本地存储，按登录身份+页面+schemaVersion分区，含条件/排序/列/单位，不存选择集、token或敏感审计原始值；失效版本提示重置。URL只放普通业务条件，追踪号仅在审计详情折叠区内查询，不传播到普通列表URL。
- 现有默认页大小20、导出硬上限100万；目标默认50、可选20/50/100/200、导出10万来自UX常量。B6b同步契约/服务端/前端/导出设置并给兼容错误提示和容量验收，不在文档提交阶段声称已生效。盘点200仅渲染窗口，绝非单据容量。
- 性能验收固定同机配置（CPU/内存/存储、Node/MySQL版本）、数据量（至少1万主单与10万明细/流水）、并发1及5、冷启动/热缓存分别不少于30次，报告原始样本及p95；各页目标独立判定，不用热缓存掩盖冷首屏。缓存TTL常量，库存/确认/更正/日期更正后失效，响应带asOf/watermark，不混水位拼指标。

## 12. 状态模型与切换单例外

部分发货/短关依赖DOMAIN_RULES §5.1的批次、独立包吨余额与M-SHIPMENTS，不能只增加中文标签。既有数据库状态CHECK已在003删除，当前阻断在扫码/冻结/确认/撤销服务，B5c须同时改契约与事务。数量更正保留原值、累计差额、有效量及最近更正时间/单号。

legacy-open显示「切换承接」来源标签，状态单独显示；只提供确认和作废，详情只读，禁编辑/更正/短关/撤销。确认只计未入账余额，原号/原行/业务日期固定；PDA事实路径及作废门禁见CUTOVER_PLAN。普通历史单仍只读。
