## 2. 三层操作结构

| 层级 | 内容 | 规则 |
|---|---|---|
| 页头 | 唯一主操作 | 每页最多 1 个 primary |
| 表格工具栏 | 导出、打印（占位）、列设置、刷新、筛选 | 与批量栏同高同位 |
| 行内 | 状态主操作 + 打印 + 「更多 ▾」 | 最多 3 个可见入口 |
| 选中后 | 批量栏替换工具栏 | 已选 N｜批量导出｜批量打印｜批量撤销｜取消 |

单号列为蓝色链接进详情，行内不再放「查看」。危险动作一律进「更多」并二次确认。

## 3. 行内操作按状态驱动

入库：待确认=确认入账；已入账=打印+更多（撤销/更正/导出/流水）；历史=打印+更多；终态=更多。
出库：计划中=编辑+打印；待确认=确认出库；部分发货=继续发货+打印；已出库=打印+更多；历史=打印+更多。

## 4. 选择与批量

1. 提示条与工具栏同高同位，勾选前后表格零位移；
2. 行选中只用浅背景，不加边框、不位移；
3. 复选框点击不触发打开详情；
4. 批量栏切换不改变表格位置；
5. 批量撤销需二次确认并列出受影响单号。

## 5. 详情多入口

单号链接、整行双击、操作列查看、选中行 Enter、右键菜单（可选）。

## 6. 查询

### 6.1 快捷行（每页最多 3 项）

| 页面 | 快捷条件 |
|---|---|
| 入库 | 登记时间、单号 |
| 出库 | 建单时间、车牌号、客户 |
| 库存 | 仓库、商品 |
| 日志 | 时间、类型 |

日期默认不过滤；提供今天/昨天/本周/本月快捷。车牌、客户支持联想。

### 6.2 高级筛选抽屉

- 右侧滑出，420–480px，分组：单据 / 商品 / 往来 / 其他；
- 「筛选」显示激活数；条件以 tag 回显；全部进 URL；
- 支持保存为视图（条件 + 排序 + 列设置）。

### 6.3 商品反查

- 一个输入框模糊匹配编码/型号/品名，支持多选与任一/全部；
- 命中时行内追加「命中：编码/名称 · N 包 · X 吨」；
- 展开只显示命中明细；
- 分页按主单，禁止先 join 明细再分页；
- 结果标题显示「N 单 · M 行」；导出支持只导命中行。

索引：inbound_receipt_lines(receipt_id, product_code)、outbound_lines(order_id, product_code)、master_products(code, model, name)。

## 7. 详情页

页头（单号+状态+主操作）→ 摘要 → 明细 → 生命周期/审计；底部固定操作条；不可用操作隐藏而非灰显；更正入口只在「更多」与底部操作条。

## 8. 打印与导出

打印统一积木报表（延后），按钮 disabled + tooltip；位置：行内可见位、详情操作条。
导出：CSV/XLSX，详情页补「导出本单」。

## 9. 视觉与密度

- 卡片圆角 12px、极浅阴影；无渐变/发光/入场动画；
- 行高 40px，行内操作可点高度 ≥32px；
- 数字等宽、右对齐；
- 页面不得整体横向溢出，仅表格内部滚动。

## 10. 验收

1. 勾选前后表格位移 0px（实测）；
2. 五种详情入口逐个可用；
3. 批量栏切换不改变表格位置；
4. 商品反查：单数、命中行数、摘要合计三者一致；
5. 1440/1280 无页面横向滚动；
6. 每页最多 1 个主按钮。
