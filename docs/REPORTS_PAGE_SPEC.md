# 报表页面规范（REPORTS_PAGE_SPEC）

> 本文档中的状态、类型、结果等库值仅作实现标识；界面显示必须按 docs/UX_STANDARDS.md 映射为中文。

## 1. 定位

| 报表 | 回答 |
|---|---|
| 出入库明细 | 每一笔发生了什么 |
| 月度汇总 | 每个月进出多少、净增多少 |
| 周转率 | 货在仓里转得快不快 |
| 库龄 | 哪些货压得太久 |

口径以 docs/REPORT_SPEC.md 为准；本文件定页面、图表、联动与交互。

## 2. 统一外壳

```
┌ 页头：标题 + [收藏] [打印（占位）] [导出] ───────────────────┐
│ 时间范围 [近 12 个月 ▾]  仓库 [全部 ▾]  商品 [______] [筛选 ·N]│
├──────────────────────────────────────────────────────────────┤
│ 视觉筛选：仓库 主仓(121) 二仓(62) ｜ 方向 入库(128) 出库(96)  │
├──────────────────────────────────────────────────────────────┤
│ 口径条：按入账日 · 时间未核实 3 项 · 不可验证 12 项 ›  数据截至 10:12 │
├──────────────────────────────────────────────────────────────┤
│ 汇总卡（2–4 个，可点）                                        │
├──────────────────────────────────────────────────────────────┤
│ 图表（月报/周转/库龄）                                         │
├──────────────────────────────────────────────────────────────┤
│ 表格 + 底部固定对账行 + 合计行                                 │
└──────────────────────────────────────────────────────────────┘
```

四条规则：
1. **口径提示条常驻**，点击展开「时间未核实」「不可验证」的原因清单；
2. 默认按入账日，提供明确标注的「重述视图」开关；归期与桥接差额按REPORT_SPEC §10，页面/导出显示basis、asOf与水位，不能把重述发生额和实际入账余额混算；
   口径开关写入URL并参与查询键；重置普通筛选时保留口径选择。口径条保留 asOf 和数值流水水位，日期更正显示「日期更正：N 条」，N=0 显示「无日期更正」。N 取同快照截至 asOf 可见的全部日期更正条数（含同单不同修订），不受报表筛选影响，不以 UUID 大小推算。日期更正 UUID 不在报表或其他业务界面展示，只允许在已登录审计详情的原始数据折叠区查看。
3. **图表即筛选器**：点柱子/分段过滤表格，再点一次取消；
4. **每个指标旁有 ? 图标**，悬停显示公式与数据来源。

B7a-1 页头使用 16px 线性标题图标，提供报表收藏、禁用的打印占位和现有三范围导出入口。收藏按报表类型保存在当前浏览器，不绑定当前筛选条件；保存视图仍独立保留筛选条件。公共外壳包含筛选、口径、水位、可选图表插槽与结果区域。

## 3. 视觉筛选（Visual Filter）

大厂分析型页面的常用模式：把最常见的两三个维度做成带计数的 chip，点一下即筛选。

| 维度 | 显示 |
|---|---|
| 仓库 | 主仓 (121) · 二仓 (62) |
| 方向 | 入库 (128) · 出库 (96) |
| 类型 | 采购入库 (110) · 销售出库 (90) · 撤销 (5) · 更正 (3) |

规则：
- 计数随当前其他条件变化；
- 支持多选；
- 选中的 chip 高亮，并在 URL 中体现；
- chip 与抽屉里的同名条件联动，不重复计算。

## 4. 出入库明细

**汇总**：入库 N 单 / X 包 / Y 吨 · 出库 M 单 / A 包 / B 吨。

**表格列**：日期（入账）、方向、单号（链接）、类型、供应商/客户、仓库、商品编码/名称、包数、吨数、关联单号、备注。

目标明细默认包含撤销与更正行，各有独立类型；更正计入有效收发、不计入调整；调整只保留盘点与期初/初始化调整。现有明细只含确认/撤销，更正/抵消明细由B5d新增，不能视为已有。收发筛选不能改变固定对账行的全类型范围，筛掉更正时提示「对账含未显示类型」。

**对账行**（表底固定）：

```
期初 1,336.5930 + 入库 972.0000 − 出库 864.0000 + 调整合计 0 = 期末 1,444.5930
```

差额 ≠ 0 时显示「差异 X 吨 · 不可验证 N 项 ›」。

## 5. 月度汇总

**汇总卡**：所选期间入库吨数、出库吨数、净入库吨数；净入库 = 有效入库 − 有效出库，不等于总库存变化。

**图表**：当前所选日期范围内按月聚合的柱状（入库/出库）+ 净入库折线。默认日期预设为「近 12 个月」（含当前月，从前第 11 个月月初至上海今天），用户可修改；不是固定图窗。点某月过滤表格归 B7a-3。

**表格列**：月份、入库单数、入库包、入库吨、出库单数、出库包、出库吨、净入库、环比、同比。

B7a-2 收尾修正：收发数量列使用「入库（包）」「入库（吨）」「出库（包）」「出库（吨）」短标签，仍表示含更正与撤销的有效净额；共享列定义确保屏幕与 XLSX 列名一致，1440/1280 下表头文字不省略。

- 环比 =（本月 − 上月）÷ |上月|，上月为 0 显示「—」；
- 同比 =（本月 − 去年同月）÷ |去年同月|，无去年同期数据时显示「—」；
- 行 hover 显示当月更正数、撤销数；
- 每行带对账：月初 + 净入库 − 净出库 + 调整合计 = 月末；更正计入有效收发，不计入调整，差额标红。

## 6. 周转率

**汇总卡**：整体周转 0.42 次 / 期间 14.3 天。

**图表**：当前所选日期范围内按月聚合周转天数折线；月首/月末按筛选边界裁剪。默认日期预设为「近 6 个月」（含当前月，从前第 5 个月月初至上海昨日），用户可修改；不是固定图窗。点某点过滤该月归 B7a-3。

**表格列**：仓库、商品、期间、净出库吨、平均库存吨、周转次数、周转天数、调整笔数、盘点次数、状态。

- B7a-2 起期间默认「近 6 个月」，保留本月/上月/近 30 天/自定义；取代本页原「本月 1 日 ~ 昨日」默认值，其余 D6 完整日规则不变；
- 选到今天标「未完结」，今天不计完整日；
- 页面提示「本期含调整 N 笔、含盘点回写 M 次，均不计入净出库」；
- 状态：正常 / 无出库（天数“无法估计”）/ 不适用（M=0）/ 不可验证；
- 条件格式：周转天数 > 30 标橙，> 60 标红。

## 7. 库龄

**汇总卡**：库存 1,408.5930 吨 · 超 90 天占比 18% · 不可归龄 0.3 吨。

**图表**：五档堆叠横条（0–30 / 31–90 / 91–180 / 181–365 / >365），点某段过滤表格。

**表格列**：仓库、商品、截止日在库、五档吨数、无法归龄、覆盖率、状态。

- 截止日默认今天，可回选历史日期（取当日日终库存）；
- 无法归龄单独列示，不填入任何分段；
- 截止日余额未知时，分桶与合计都显示「不可验证」，不填 0；
- 条件格式：>90 天段标红。

## 8. 下钻

| 从 | 到 |
|---|---|
| 月报某月/某行 | 明细（该月） |
| 周转某行 | 明细（该商品，期间内） |
| 库龄某段 | 库龄表（过滤该段） |
| 库龄某商品 | 库存概览（该商品） |
| 明细某单号 | 单据详情 |
| 汇总卡数字 | 对应明细（带条件） |

下钻时新开页面并带条件，不覆盖当前页状态。

## 9. 图表规范

| 图 | 类型 | 交互 |
|---|---|---|
| 所选期间按月进出 | 柱 + 线 | 悬停显示单数/包/吨；点柱过滤归 B7a-3 |
| 周转天数 | 折线 | 点过滤、悬停显示明细 |
| 库龄结构 | 堆叠横条 | 点分段过滤 |

ECharts 按需注册（Line、Bar + Grid、Tooltip、Legend、CanvasRenderer），自封 `<Chart>` 组件。
配色：入库chartTheme.inbound、出库chartTheme.outbound，网格线colorBorderSecondary，全部来自theme token。
依赖固定为 `echarts@6.1.0`（Apache-2.0）；只引入 ECharts 核心包，不引入 React wrapper。

### B7a-2 实施边界（2026-11-14）

- 三页原响应增加 `chart`，明细响应不增加。图表、全筛选范围汇总卡及分页表格共享一次响应、basis、asOf、流水和日期更正水位；分页/排序不改变图表聚合。聚合只在服务端执行，浏览器不接收全量表格行。月报聚合采用整数克，展示时折吨；单数按月跨仓品去重，不累加各仓品单数。
- 周转每月和整个区间均用总净出库 O 与总日终库存累计值 S 重算：M=S/D、R=O/M、T=S/O；不得平均各仓品比率或月度天数。完整日受 asOf 限制，重述只改变 O 的归期，M/FIFO 仍按入账序列。任一纳入仓品不可验证则保留 null 与原因，不缩小统计子集。
- 库龄五档保持 0–30 / 31–90 / 91–180 / 181–365 / >365 天；不可归龄是独立第六段，不并入任何年龄桶。五档 + 不可归龄 = 同截止库存。超 90 天占比 = 后三档合计 / 截止库存；仅代表已知超龄量占账面库存，未知年龄不推测，零库存或未知值显示「—」及原因。
- 卡片：月报入库/出库/净入库，周转次数/天数，库龄截止库存/超 90 天占比/不可归龄；均取全筛选范围 totals 或 chart 合计，使用现有 StatCard，附公式和数据来源提示。本批卡片和图表不做点击过滤/下钻，归 B7a-3。
- Chart 仅注册 LineChart、BarChart、GridComponent、TooltipComponent、LegendComponent、CanvasRenderer。容器固定高度，ResizeObserver 只调用 resize，更新数据调用 setOption，不因宽度变化重建实例，卸载释放资源；系列、文字、坐标轴、网格、提示框颜色全部取 theme token。
- 加载、空数据、请求错误分别显示；未知指标显示原因，不填 0。切换日期/basis/筛选时图表、卡片和表格整体进入加载态，新响应一起展示，避免旧图新表；无数据不画空坐标轴。导出仍直接使用报表服务，不依赖图表渲染。
- 本批不做视觉筛选 chips、下钻联动、表底对账行、导出文件名；这些归 B7a-3。原 §2/§8/§9 的可点击行为是后续目标，不作为 B7a-2 已完成能力。
- 验收包含聚合与全分页行合计一致、周转总分子/分母重算、不可归龄独立段、空态/错误/加载、basis 同步、默认范围改短后图表与表格同步，以及 design token 新增违规为 0；三页 1440/1280 截图仅存 `.local/evidence/`。

## 10. 导出与打印

- 导出沿用三范围：全部筛选 / 当前页 / 选中；
- 导出内容含汇总、表格、对账行；
- 导出文件名：`{报表名}_{起始日}_{截止日}.xlsx`；
- 打印按钮占位，版式按 A4 纵向表格化（后续接积木）。

## 11. 状态与反馈

| 情况 | 表现 |
|---|---|
| 加载 | 保留筛选与页头，表格骨架，图表稳定替换、不加装饰入场动画 |
| 无数据 | 表格空态 + 「本期没有出入库记录」，图表显示空态说明 |
| 指标无法计算 | 显示「—」并给原因，不显示 0 |
| 不可验证 | 行级标记 + 口径条计数，点击看清单 |
| 数据过期 | 口径条右侧显示「数据截至 HH:mm」，可手动刷新 |

## 12. 性能

- 报表接口服务端聚合，缓存 30 秒；
- 明细 10 万行分页，图表只取聚合值；
- 图表数据与表格一次请求返回，避免二次加载。

## 15. 验收

1. 数量按全筛选范围累加，单数按业务单号去重、比率按总分子/分母重算；跨月期初/期末不相加，分页合计与全量summary分别验证；
2. 明细对账行等式成立，差额可见；
3. 月报 12 柱 + 环比 + 同比计算正确，点柱过滤生效；
4. 视觉筛选 chip 计数随条件变化，与抽屉联动不重复；
5. 周转三种边界（无出库 / M=0 / 不可验证）各一条；
6. 库龄五档 + 不可归龄 = 截止日库存；
7. 六条下钻路径全部可达且条件正确；
8. 指标 ? 悬停显示公式；
9. 导出与屏幕逐字段一致（抽 1 个月、1 个商品）；
10. 1440/1280 截图（四页，含图表、对账行、不可验证提示、视觉筛选）。

## 16. 服务能力与验收补充

B5d先补更正/抵消明细、独立分类与日期更正/重述投影，再由B7a（UI-5）提供图表/下钻。重述不能给更正单新增business_date：通过原单及追加式日期更正记录取有效日期。有效更正量计入对应收发，调整仅含盘点与期初/初始化调整；更正、盘点、期初/初始化调整与其他库存变动互斥分类，其他库存变动不并入调整；原单撤销的更正抵消仍在更正分项，不挤入收发量。样品出库计出库且单列类型，取样只计包数/次数。

导出三范围及命中粒度复用WEB_UX_SPEC；时间/类型条件变化重新取token。缓存使用共同水位，库存/更正/日期更正后失效，TTL不能代替一致性；性能遵循公共冷/热基准，保留B3c冷首屏未达标状态。数量更正分列本身不需新库存表；日期历史需M-DATE-CORRECTIONS，正式T0依赖M-CUTOVER-ANCHOR。逐页验收默认/重述标签、跨月原单+更正+抵消不双计、未知日期不填0、导出与同basis页面一致。
