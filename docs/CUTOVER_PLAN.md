# 切换方案（CUTOVER_PLAN）

## 1. 目标

把老系统（erp.nbsmzwl.cn）的**期初库存、未完成单据、主数据**一次性搬进本系统，之后老系统只读归档。
不迁移历史单据的可操作性——历史单据如需查询，按只读导入保留。

## 2. 原则

1. 切换是一次性动作，中途失败可回退到老系统继续用；
2. 期初库存有且只有一次，导入后**锁定**，只能通过库存调整修改；
3. 单号切点明确：老系统单号保留原样（只读），新单从 RK-/CK- 开始，绝不复用；
4. 切换前必须做一次完整演练，演练库与正式库同一套脚本。

## 3. 前置条件（T-7 天）

| # | 条件 | 负责 |
|---|---|---|
| 1 | 本系统规格定稿、页面改造完成、打印可用 | 开发 |
| 2 | 商品/客户/供应商/车辆主数据核对完成 | 业务 |
| 3 | 库存实物盘点完成，账面与实物一致 | 业务 |
| 4 | 老系统停止新增单据的时间点确定 | 业务 |
| 5 | 备份与恢复演练通过（含恢复后对账） | 开发 |
| 6 | PDA 新版安装包与目录版本准备就绪 | 开发 |

## 4. 切换日流程

### T-1 天

```
① 老系统最后一批出入库全部确认，无挂起单据
② 老系统做一次全量备份（库 + 上传文件）
③ 本系统在演练库完成一次完整切库演练并留记录
```

### T 日（切换当天）

```
08:00  老系统置为只读（禁止新建/确认，可查询）
08:10  导出：库存快照、未完成单据、主数据、编号计数器
08:30  导入本系统：
         - 主数据（商品/客户/供应商/车辆）
         - 期初库存（按仓库×商品，包数+吨数）
         - 未完成入库单（未确认）
         - 未完成出库单（计划中/已冻结/部分发货）
         - 编号计数器起始值
09:00  校验（见第 6 节），差异逐项清零
09:30  业务试跑：登记 1 张入库、确认入账、查库存
10:00  正式启用本系统，老系统保持只读
```

### T+1 ～ T+7

```
每日核对：本系统库存 = 期初 + 当日入 - 当日出 ± 调整
异常登记与处理；PDA 全量补传完毕
```

## 5. 期初库存导入

| 项 | 规则 |
|---|---|
| 来源 | 老系统切换时刻的库存表（只读快照） |
| 粒度 | 仓库 × 商品 |
| 字段 | 包数（整数）、吨数（4 位小数）、来源标记 `opening` |
| 一致性 | 导入前后总包数、总吨数、商品数必须一致 |
| 锁定 | 导入完成后写入 `stock_opening` 标记，界面只读，改动只能走库存调整 |
| 审计 | 导入批次号、操作人、时间、文件哈希 |

## 6. 校验清单（必须全部为 0 差异）

1. 商品数、客户数、供应商数、车辆数一致；
2. 每个仓库的库存行数一致；
3. 每个仓库的总包数、总吨数一致；
4. 逐商品（仓×品）差异 = 0，允许的舍入误差为 0；
5. 未完成单据数量与单号一致；
6. 单号计数器起始值大于老系统最大号；
7. 期初库存总额 = 本系统库存合计（导入后立即查）。

任一项不为 0：停止切换，回退到老系统。

## 7. 单号切点

| 单据 | 老系统 | 新系统 |
|---|---|---|
| 入库 | `IN2026…`（保留） | `RK-YYYYMMDD-####` |
| 出库 | `OUT2026…`（保留） | `CK-YYYYMMDD-####` |
| 更正 | — | `GZ-YYYYMMDD-####` |
| 盘点 | — | `PD-YYYYMMDD-####` |

规则：
- 老单号只读，不参与新编号；
- 新编号计数器从 1 开始，按日期分段；
- 禁止手工输入旧格式单号。

## 8. 未完成单据处理

| 类型 | 处理 |
|---|---|
| 老系统未确认入库单 | 导入为待确认单，需在新系统重新确认才入账 |
| 老系统计划中出库单 | 导入为计划单，可继续扫码确认 |
| 已冻结未确认出库单 | 导入事实与冻结状态，Web 确认后扣库存 |
| 进行中盘点 | 老系统作废后重来（不迁移半成品） |
| 待补传 PDA 事实 | 切换前必须全部补传完毕，否则阻断切换 |

## 9. 回滚预案

切换后 7 天内，若出现无法短期修复的问题：

```
① 本系统停止写入
② 老系统取消只读，恢复使用
③ 本系统期间产生的单据人工补录到老系统（或作废）
④ 记录回滚原因与影响范围
```

7 天后不再回滚，只做前向修复。

## 10. 角色与产出

单用户执行，但需留下记录：

| 产出 | 内容 |
|---|---|
| 切换记录 | 时间线、每步结果、操作人 |
| 校验报告 | 第 6 节七项的实际数字 |
| 期初导入文件 | 原始 CSV + 哈希 |
| 演练记录 | 演练库的同样校验结果 |

## 11. 验收

1. 演练库完整跑通一次切换，七项校验为 0；
2. 正式切换七项校验为 0；
3. 期初导入后库存只读，修改只能走调整；
4. 新单号从 RK-/CK- 起，老单号不可新建；
5. 未完成单据在新系统可继续操作；
6. 切换后 7 天每日对账通过；
7. 回滚演练一次（在演练库完成，不碰正式）。
