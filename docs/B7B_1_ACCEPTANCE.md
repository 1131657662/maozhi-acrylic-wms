## 实现范围

- `/` 为工作台；`/outbound` 为独立出库列表。旧根地址含任一现有出库列表参数则 replace，原查询串（含重复参数）与 hash 保留；裸根地址不推测旧书签。详情返回、新建取消、登录恢复、AuthGate 与 listReturn 已统一，外站 redirect 被拒绝。
- `/api/v1/web/dashboard` 仅登录 Web 可读；八块同一只读一致性事务，同一 asOf/watermark。缓存30秒，复用写版本时钟，合并同版本并发请求，读期间发生写入不缓存旧快照；失败响应不缓存。
- 收发复用报表 posted/inventory 归期校验、normalizeEvent/addMovement。确认、撤销、数量更正及样品归入对应有效收发，调整/盘点不混入。无历史待办快照时明确原因；缺数据或失败为 null，已核验空集才为0。
- 待办准确总数与每类最多5条详情链接；盘点和扫码超时各有独立列。目录、交接、车号、最近安全投影和快捷入口均可操作。SVG 在数字首次绘制后加载；侧栏订阅同一聚合结果，取消原盘点专用轮询。业务写入后失效客户端查询，列宽偏好保存不触发首页刷新。
- 待办单号、仓库与车号复用既有审计安全文本投影；异常旧值含UUID时显示中文缺失提示，详情链接仍可用，不把内部标识作为业务名称。
- 不做看板/analysis、热力图、Top、时效、取样、设备实时状态或旧书签提示。未改库存写链路、扫码协议、生产连接、数据库迁移、依赖或测试框架。
- 为避免串行等待，根页面head尽早启动唯一聚合请求，页面加载和查询并行；共享query一次消费该响应，复用统一响应/契约校验，仍受接口鉴权和30秒有效期约束。登录成功丢弃之前的预取，网络失败不因第二个订阅者挂载而自动重试，用户可刷新恢复。

## 性能方法与限界

复用既有随机 `maozhi_test_*` 临时库和生产 build 静态服务；验收后销毁临时库，未写开发样本库。种子包含入/出库主单各10000、明细各100000、库存流水100001；收发事实分布在当前14天，含当前待办、盘点和扫码超时。均为合成数据，非历史迁移。

正式样本并发1/5，冷/热各30个：冷组每批清服务端缓存、浏览器使用新上下文；热组预热服务端与浏览器。冷指应用缓存冷、浏览器上下文冷，不宣称清空MySQL buffer pool或操作系统磁盘缓存。接口计完整HTTP响应及解析；首屏从导航开始至KPI/待办存在并经过浏览器绘制周期，不以骨架屏计完成。部分失败/未知样本保留并计入invalidSamples，任何非零都使该组不通过；阈值保持1000ms。夹具复用原报表性能数据，单商品纯入库流水分散到14个日期午夜，不将此结果外推为任意时间/商品分布均达标。

SQL按固定类别批量读取；历史流水先压缩可加差额，日期共享 JSON_VALUE 安全解析及报表有效日期校验；更正/本地流水保留分类依据。待办用窄计数和4个限量投影，避免全量宽行窗口排序。诊断初版超过750ms查询上限；JSON解析与待办投影优化后单次诊断快照约704ms（收发581ms、待办57ms）。诊断值不替代最终30次p95。

验收主机：Windows 10.0.26300，Intel i5-11400F 2.60GHz（12逻辑核），内存34252378112字节（约31.9GiB），D盘为WDC WDS500G2B0C NVMe 500GB；Node v24.14.1、MySQL 8.0.46，InnoDB buffer pool 128MiB。MySQL数据目录位于项目.local/mysql/data；localhost同机，无网络限速或CPU降速。
