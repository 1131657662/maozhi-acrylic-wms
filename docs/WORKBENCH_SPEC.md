# 工作台与数据看板规范（WORKBENCH_SPEC）

> 本文档中的状态、类型、结果等库值仅作实现标识；界面显示必须按 docs/UX_STANDARDS.md 映射为中文。

## 1. 两页分工

| | 工作台（/） | 数据看板（/dashboard） |
|---|---|---|
| 回答 | 我现在该干什么 | 生意在往哪走 |
| 时间 | 今天 | 本月 / 本年 / 近 12 月 |
| 交互 | 可操作 | 只读 + 下钻 |
| 刷新 | 30 秒 | 进入时一次 |
| 加载 | < 1 秒 | < 2 秒 |

工作台是干活的地方，看板是看数的地方。

## 2. 工作台结构

| 区块 | 内容 | 交互 |
|---|---|---|
| KPI ×4 | 今日入库、今日出库、待确认、进行中盘点（各带环比与迷你趋势） | 点击进对应列表/详情 |
| 待我处理 | 待确认入库/出库、冻结超时、锁仓盘点 | 每行直达处理 |
| 目录健康 | 当前版本、条码数、上次更新、本版新增/消失/重量变更 | 去上传 |
| 设备数据 | 待补传事实数、冲突数 | 查看 |
| 今日车辆 | 在装 / 待确认 / 已离场 | 进出库单 |
| 最近操作 | 最近 10 条 | 操作记录 |
| 快捷入口 | 登记入库、新建出库、开始盘点、上传目录 | — |
| 14 天迷你趋势 | 入库/出库两条线 | 进看板 |

规则：
- 除迷你趋势外每个区块都能点或操作；
- 进行中盘点与冻结超时必须首屏可见；
- 只发一个 /api/v1/web/dashboard 请求，缓存 30 秒；
- 空态给可执行动作，不给空白卡片。

## 3. 数据看板结构

| 区块 | 图表 |
|---|---|
| 时间范围 | 本月/上月/今年/去年/自定义（全局） |
| 12 个月趋势 | 折线/面积，入库 vs 出库，可切吨数/包数 |
| 月度对比 | 柱状 + 环比 |
| Top 排行 | 商品 / 客户 / 供应商 三列横条 |
| 库龄结构 | 五档堆叠条 |
| 周转趋势 | 近 6 个月周转次数与天数 |
| 日历热力 | 近 6 个月每日吨数 |
| 单据时效 | 平均确认时长、最长滞留单 |

看板不放任何写操作；与工作台共用同一聚合服务。

## 4. 下钻

| 点击 | 跳转 |
|---|---|
| 某月柱 | 月度汇总（该月） |
| 某天热力格 | 出入库明细（该日） |
| Top 商品行 | 明细报表（该商品） |
| Top 客户行 | 出库明细（该客户） |
| 库龄段 | 库存列表（该段） |
| 周转点 | 周转率报表（该期间） |
| 工作台待办 | 对应单据详情 |

## 5. 图表

ECharts 按需注册（Line/Bar/Pie + Grid/Tooltip/Legend/CanvasRenderer），自封 <Chart> 组件（init + ResizeObserver + dispose），不用 echarts-for-react。
迷你趋势线用 SVG 手写。
配色：主色 #105957 + 中性灰蓝 #8aa3a0；网格线 colorBorderSecondary。

## 6. 接口

GET /api/v1/web/dashboard → today、pending、stocktake、stale、stock、trend14d、topProducts、topCustomers、recent
GET /api/v1/web/analysis?from=&to= → monthly、tops、aging、turnover、heatmap、duration
两接口均服务端聚合，缓存 30 秒。

## 7. 边界

| 情况 | 处理 |
|---|---|
| 无数据 | 卡片显示 0 并给动作入口，不显示空白图表 |
| 进行中盘点 | 必须显示，且显示锁仓时长 |
| 图表数据缺失 | 显示「暂无数据」占位，不画空坐标轴 |
| 聚合超时 | 显示部分数据 + 顶部提示「部分数据加载失败」 |

## 8. 验收

1. KPI 数字与对应列表条数一致；
2. 进行中盘点与冻结超时首屏可见；
3. 工作台只发一个请求，p95 < 1s；
4. 看板 8 个区块均有数据或空态；
5. 六条下钻路径可达且条件正确；
6. 1440 一屏放下前两行，1280 无横向滚动；
7. 1440/1280 截图。
