# 消息中心 / 系统维护 / 个人中心 规范（OPS_PAGES_SPEC）

> 本文档中的状态、类型、结果等库值仅作实现标识；界面显示必须按 docs/UX_STANDARDS.md 映射为中文。

## 一、消息中心

### 1. 定位

只做**系统通知**：有事提醒我，点一下能到现场。不做公告、私信、@人、已读回执。

### 2. 页面结构

```
┌ 消息中心 ─────────────────────── [全部已读] ┐
│ 未读 3 ｜ 全部 12 ｜ 类型 [全部 ▾]          │
├──────────────────────────────────────────────┤
│ ● 11-09 10:12  待确认  入库单 RK-…031 待确认 │
│ ● 11-09 09:40  超时    出库单 CK-…008 冻结 8 天 │
│ ● 11-08 18:00  备份    每日备份失败（磁盘不足）│
│ ○ 11-08 09:00  盘点    主仓盘点进行中 12 小时 │
└──────────────────────────────────────────────┘
```

点一条 → 直接跳到对应单据/页面，并标记已读。

### 3. 消息类型

| 类型 | 触发 | 跳转 |
|---|---|---|
| 待确认 | 入库创建待确认/出库冻结待确认超过2小时，尚未入账 | 单据详情 |
| 冻结超时 | 出库单冻结超过 7 天未确认 | 单据详情 |
| 盘点未结束 | 盘点锁仓超过 24 小时 | 盘点详情 |
| 目录待更新 | 距上次上传超过 30 天 | 条码目录 |
| 备份失败 | 备份任务失败 | 系统维护 |
| 异常 | 历史异常负余额（诊断，不允许新写负库存）、盘点差异超提示阈值 | 对应页面 |

生成方式：服务端定时任务扫描，**同一对象同一类型同一事件周期只保留一条活动通知**（已读不自动重发，条件解除记录resolved，新周期才新建），避免轰炸。

### 4. 交互

- 未读数显示在左侧菜单角标；
- 支持「全部已读」；
- 单条已读在点击跳转时自动完成；
- 消息保留 90 天，过期自动清理（仅删通知，不动业务数据）；
- 不做消息回复、不做评论。

### 5. 接口

GET /api/v1/messages?type=&unread=&page=
POST /api/v1/messages/:id/read
POST /api/v1/messages/read-all
GET /api/v1/messages/unread-count

### 6. 边界

| 情况 | 处理 |
|---|---|
| 对象已删除 | 消息保留，跳转提示“对象不存在” |
| 重复触发 | 同事件周期合并last_seen/count，不重置已读；条件解除后标已恢复 |
| 免打扰 | 不做（单用户，量很小） |

## 二、系统维护

### 1. 定位

保证两件事：**数据有备份、系统没毛病**。

两个 Tab：备份 | 健康。

### 2. 备份 Tab

```
┌ 备份 ────────────────────────── [立即备份] ┐
│ 最近成功：2026-11-09 02:00（8 小时前）✓      │
│ 磁盘剩余：120 GB                           │
├─────────────────────────────────────────────┤
│ 时间 │ 类型 │ 大小 │ 校验 │ 状态 │ 操作     │
│ 11-09 02:00 │ 自动 │ 42 MB │ ✓ │ 成功 │ 下载/恢复 │
│ 11-08 02:00 │ 自动 │ 42 MB │ ✓ │ 成功 │ 下载/恢复 │
│ 11-07 18:20 │ 手动 │ 41 MB │ ✗ │ 损坏 │ 下载/删除 │
└─────────────────────────────────────────────┘
```

规则：
- 每日自动备份 1 次（凌晨）；
- 保留策略：30 个日备 + 12 个月备，超出自动清理；
- 每次备份写 SHA-256 与大小清单；
- 下载前校验哈希；
- 备份失败 → 消息中心 + 页面顶部红色提示。

### 3. 恢复（危险操作）

```
① 点击恢复 → 弹窗列出：备份时间、大小、校验状态
② 要求输入 “RECOVER” 确认
③ 自动先备份当前库（防止越恢复越糟）
④ 恢复到隔离库 → 校验表数量、行数、库存合计
⑤ 校验通过后提示“需手动切换到恢复库”，不自动切换
⑥ 失败先保全日志/指纹/错误证据，再清理本任务创建且核验归属的隔离库，原库不动
```

明确：**不在原库上直接覆盖恢复**。

### 4. 健康 Tab

| 区块 | 内容 |
|---|---|
| 数据库 | 连接状态、版本、表数量、慢查询数（近 24h） |
| 磁盘 | 剩余空间、数据目录大小、备份目录大小 |
| 服务 | 运行时长、近 24h 请求数、错误数、p95 耗时 |
| 备份 | 最近成功时间、最近失败原因 |
| 任务 | 最近定时任务执行结果（备份、消息扫描） |

异常项标红，正常项绿点。

### 5. 接口

GET /api/v1/maintenance/backups
POST /api/v1/maintenance/backups
GET /api/v1/maintenance/backups/:id/download
POST /api/v1/maintenance/backups/:id/restore
DELETE /api/v1/maintenance/backups/:id
GET /api/v1/maintenance/health

### 6. 边界

| 情况 | 处理 |
|---|---|
| 磁盘不足 | 备份前检查，直接拒绝并提示 |
| 备份超大 | 记录大小，超阈值告警 |
| 恢复中断 | 保全诊断与任务状态后清理本任务隔离库，原库不变 |
| 无备份 | 顶部红条「从未备份」 |
| 并发备份 | 同一时间只允许一个 |

### 7. 不做

| 不做 | 原因 |
|---|---|
| 云备份 | 单机部署，本地 + 手动下载够用 |
| 定时任务可视化编辑 | 固定任务，代码里配置 |
| 数据库迁移工具界面 | 迁移由脚本执行 |

## 三、个人中心

### 1. 定位

单用户的最小身份页：改密码、看会话、退出。

### 2. 页面结构

```
┌ 个人中心 ─────────────────────┐
│ 账号 owner（管理员）           │
│ 上次登录 2026-11-09 08:30     │
│ 当前会话 到期 16:30           │
├────────────────────────────────┤
│ 显示名 [owner________] [保存] │
│ 修改密码                       │
│  原密码 [________]            │
│  新密码 [________]            │
│  确认   [________]            │
│  [修改密码]                    │
├────────────────────────────────┤
│ [退出登录]                     │
└────────────────────────────────┘
```

规则：
- 改密码需原密码；
- 新密码长度 ≥ 12，含字母与数字；
- 改密后Web/PDA/小程序所有会话同事务失效并重新登录；PDA本地未传UUID/正文及离线队列保留，重新认证后继续原样补传；
- 显示名仅影响页面右上角，不影响账号；
- 不做头像、邮箱、手机号（单用户无意义）。

### 3. 接口

GET /api/v1/me
PUT /api/v1/me/profile
POST /api/v1/me/password
POST /api/v1/me/logout

### 4. 边界

| 情况 | 处理 |
|---|---|
| 原密码错误 | 422，保留输入 |
| 新密码不合规 | 422，提示规则 |
| 改密后会话 | 立即失效，跳登录 |
| 登录失败次数 | 连续 5 次锁定 15 分钟 |

## 四、验收

### 消息中心
1. 未读数与列表一致，点开自动已读；
2. 同一对象同类型同事件周期仅一条活动通知，已读后不因扫描重发；恢复后新周期可重新通知；
3. 六种类型各触发一次，跳转正确；
4. 90 天后过期清理不影响业务数据。

### 系统维护
5. 手动备份成功，列表显示大小与校验；
6. 备份失败时消息中心与页面同时提示；
7. 恢复需输入确认词，自动先备份当前库；
8. 恢复失败时原库不变（给实际输出）；
9. 磁盘不足时拒绝备份；
10. 健康指标逐项标采集来源/水位，未接采集器显示不支持而非0，异常项标红。

### 个人中心
11. 改密码需原密码，成功后强制重新登录；
12. 新密码不合规被拒；
13. 连续 5 次登录失败锁定 15 分钟。

### 通用
14. 1440/1280 截图（消息列表、备份列表、恢复确认、健康页、个人中心）。

## 五、服务/表依赖与批次（当前需要新增服务能力）

| 批次 | 新服务/表 | 契约及边界 |
|---|---|---|
| B8a / UI-8维护 | M-MAINTENANCE：maintenance_jobs、backup_artifacts、restore_verifications、scheduler_runs | 任务保存kind/status/idempotency_key/actor/起止/错误/归属；产物保存SHA256/字节数/私有引用/保留期限，恢复保存原库及副本指纹/逐表计数/仓品包吨/迁移版本与校验报告 |
| B8b / UI-8身份 | M-AUTH-EXTENSIONS：账户display_name/password_changed_at/锁定计数与期限；会话失效版本、登录尝试证据 | 当前只有登录/me/logout与限流20，5次15分钟为新增持久策略，不能把HTTP限流冒充账户锁定；新增改密、会话查询/撤销接口，保留现有认证路由兼容 |
| B8c / UI-8通知 | M-NOTIFICATIONS：notifications、notification_scan_state | 通知保存event_key/type/target/business_no、first_seen/last_seen/count、read_at/resolved_at、expires_at；活动event_key唯一，事务游标扫描+幂等upsert，90天只清通知不清审计 |

维护接口是异步任务：POST返回jobId、GET读取状态，不让浏览器执行任意路径/命令/目标库名。备份/恢复按任务互斥、超时/重启可查；清理只针对自身产物且已核验归属。当前backup/restore仅CLI；恢复副本现有清空会话行为在指纹中明确排除并验证，其余业务表必须逐项对账。UI中的恢复不覆盖原库，切换连接另有CUTOVER门禁；不自动触发迁移。

健康页需要数据库/磁盘/HTTP耗时及错误采集服务，记录采集时间/窗口和缺测原因；慢查询数、24小时p95在未启用采集器时标不支持。车辆离场/实时设备队列始终不由维护页猜测，沿用WORKBENCH/CATALOG证据范围。账户密码/token不进审计，失败尝试依赖B6c；改密/会话撤销认证检查在服务端，单用户不引入RBAC。

新迁移编号从012按实施顺序分配，up保留来源与历史证据，非空业务/任务/通知记录拒绝破坏性down。查询/分页/导出和唯一主操作遵循WEB_UX_SPEC，不在三页各定一套。阶段先维护与身份，再接稳定事件做通知；演练、实体与生产结果分别记录。
