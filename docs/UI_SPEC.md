# UI 规格

以下规格覆盖矩阵中的页面族。每页不超过 10 行；页面沿用 Ant Design Pro 的 ProLayout、ProTable、ProForm、ProDescriptions，四态统一为加载、空态、错误可重试、无权限。

## 登录与首页

- 页面目的：让单用户快速进入当前待办和最近业务。
- 信息层级：产品名/当前模块 → 待处理单据 → 库存与消息摘要。
- 文字线框：顶部身份；左侧导航；主区统计条、待办表格、最近操作。
- 主操作：进入待扫码、待确认、待审核。
- 四态表现：骨架屏；无待办空态；卡片内重试；无权限显示原因。
- 优化：把旧首页分散入口收成一张待办表，首屏能回答位置、对象、下一步。

## 基础资料列表族

- 页面目的：维护商品、仓库、供应商、客户并保留历史引用。
- 信息层级：筛选栏 → ProTable 关键列 → 行内启停/编辑。
- 文字线框：页面标题；编码/名称/状态筛选；表格；新增抽屉。
- 主操作：新增主数据；行内编辑和启停。
- 四态表现：表格加载；无结果空态；重试保留筛选；无权限禁用写操作。
- 优化：四类资料共用列表壳，避免旧系统各页操作位置不同。

## 入库新建/详情

- 页面目的：登记包数与本次总吨数，确认后原子更新库存。
- 信息层级：单据头 → 明细行 → 合计/库存影响 → 确认。
- 文字线框：ProForm 头部；ProTable 明细；右侧合计；底部固定确认。
- 主操作：保存草稿、提交/确认；单号由编号规则生成并预览。
- 四态表现：字段级校验；空明细提示；失败可重试且保留输入；无权限只读。
- 优化：包数和总吨数并列录入，禁止用统一件重反算。

## 入库列表

- 页面目的：按单号、日期、状态、供应商、仓库查找入库单。
- 信息层级：组合筛选 → ProTable → 导出/批量操作。
- 文字线框：筛选栏；列显隐；固定操作列；分页；导出按钮。
- 主操作：查看详情、编辑草稿、撤销/更正（按状态）。
- 四态表现：表格加载；无数据；查询失败重试；无权限只读。
- 优化：旧系统关键词搜索升级为可保存的多条件筛选。

## 出库新建/详情

- 页面目的：创建计划，接收 PDA 扫码事实，Web 明确确认扣库存。
- 信息层级：计划头 → 计划/实扫对比 → 包级事实 → 确认影响。
- 文字线框：ProForm 计划头；ProDescriptions 摘要；事实表；确认抽屉。
- 主操作：创建/编辑计划；查看事实；冻结状态后确认出库。
- 四态表现：事实加载；未扫码空态；接口错误可重试；PDA/小程序会话无权限。
- 优化：冻结与出库确认分层，避免旧 ERP 审核按钮同时承担两种语义。

## 出库列表

- 页面目的：按单号、日期、状态、客户、仓库追踪出库计划。
- 信息层级：多条件筛选 → ProTable 关键业务列 → 固定操作。
- 文字线框：筛选栏；状态标签；包数/吨数；详情/编辑/导出。
- 主操作：新建计划、打开详情、批量导出。
- 四态表现：加载、空结果、可重试错误、无权限只读。
- 优化：列显隐和筛选持久化，减少重复配置。

## 库存查询/调整

- 页面目的：查看有效库存并通过原因明确的调整留痕。
- 信息层级：来源口径/仓库筛选 → 库存行 → 流水/调整。
- 文字线框：筛选栏；库存表；流水抽屉；调整抽屉。
- 主操作：查看流水、发起调整；调整前展示前后包数/吨数。
- 四态表现：加载、零库存空态、重试、无权限只读。
- 优化：商品来源标签阻止 141 SPEC 与 428 ERP 商品被误合计。

## 盘点

- 页面目的：创建盘点快照、录入实盘、处理差异并回写库存。
- 信息层级：盘点头 → 系统库存/实盘输入 → 差异 → 回写或作废。
- 文字线框：ProForm 仓库/日期；可编辑明细表；差异汇总；确认抽屉。
- 主操作：加载库存、确认盘点、差异回写、作废。
- 四态表现：加载快照；无库存空态；回写失败可重试；无权限只读。
- 优化：差异在同表即时出现，减少旧系统页面跳转。

## 统计报表

- 页面目的：提供月度汇总、周转率、出入库明细和库龄分析。
- 信息层级：周期/来源口径 → 指标摘要 → 表格/图表 → 导出。
- 文字线框：筛选栏；指标条；ProTable；导出和下钻。
- 主操作：查询、排序、导出；来源口径始终可见。
- 四态表现：计算加载；无数据空态；失败重试；无权限隐藏数据。
- 优化：表格字段顺序与导出完全一致，避免旧系统屏幕与 Excel 不同。

## 系统配置

- 页面目的：维护字典、参数和单据编号规则。
- 信息层级：配置分组 → 当前值/新值 → 影响范围 → 保存审计。
- 文字线框：Tabs 分组；ProTable/ProForm；规则预览；保存确认。
- 主操作：新增/编辑字典项、保存参数、预览下一个单号。
- 四态表现：加载、空配置、重试、无权限只读。
- 优化：编号规则直接展示下一个结果，减少旧系统保存后才发现格式错误。

## 系统监控

- 页面目的：查询操作日志和当前会话，支持审计排查。
- 信息层级：时间/用户/模块筛选 → 日志表 → 前后值详情。
- 文字线框：ProTable；traceId；详情抽屉；在线会话表。
- 主操作：筛选、查看详情、失效会话、导出。
- 四态表现：加载、空态、错误重试、无权限拒绝。
- 优化：日志详情按一次操作聚合前后值，减少旧系统翻查多条记录。

## 消息中心

- 页面目的：集中展示通知、提醒、预警和公告，并跳转到业务对象。
- 信息层级：未读筛选 → 消息列表 → 详情/关联单据。
- 文字线框：未读计数；ProTable；详情抽屉；批量已读。
- 主操作：打开消息、标记已读、跳转。
- 四态表现：加载、无消息、重试、无权限空态。
- 优化：从消息到目标单据保持 2 步以内。

## 个人中心

- 页面目的：修改密码和必要的个人显示信息。
- 信息层级：身份摘要 → 密码表单 → 可修改资料。
- 文字线框：ProDescriptions；Tabs；ProForm；会话提示。
- 主操作：修改密码、保存显示名/联系方式。
- 四态表现：加载、无额外资料空态、错误重试、无权限只读。
- 优化：单用户不引入角色编辑、头像等不影响作业的复杂字段。
