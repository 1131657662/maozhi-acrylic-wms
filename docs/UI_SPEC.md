# UI 规格

页面统一使用 Ant Design Pro 的 ProLayout、ProTable、ProForm、ProDescriptions。每族均定义 4 态：加载、空态、错误可重试、无权限；页面不覆盖 `.ant-*` 内部样式，断点、列固定和文案按本文件执行。

用途隔离：库存与单据只认 `erp-product`；`sku-spec` 仅属于 B1c 条码目录用途（B1c-1 已验证，设备同步留 B1c-2），不设库存入口。下列后续布局规范不等同于本轮全部实现。

## 登录与首页

- 页面目的：单用户登录后直接看到待处理工作。
- 信息层级：产品名/当前位置 → 待处理单据 → 库存与消息摘要。
- 文字线框：顶部身份；左导航；统计条；待办表；最近操作。
- 主操作：进入待扫码、待确认、待审核。
- 四态文案：加载“正在加载工作台…”；空态“暂无待处理事项”；错误“工作台加载失败，请重试”；无权限“当前身份不能访问此模块”。
- 响应式：≥1200px 左侧导航 232px；768–1199px 导航可收起；<768px 顶部导航，内容宽度 100%。
- 表格策略：待办表固定单号/状态/操作列，操作列右固定；其余列可隐藏。
- 优化：旧首页分散入口合并为一张待办表，首屏回答位置、对象、下一步。

## 基础资料列表族

- 页面目的：维护商品、仓库、供应商、客户并保留历史引用。
- 信息层级：筛选栏 → ProTable 关键列 → 行内启停/编辑 → 抽屉表单。
- 文字线框：标题与新增；编码/名称/状态筛选；表格；新增/编辑抽屉。
- 主操作：新增主数据；行内编辑和启停。
- 四态文案：加载“正在加载主数据…”；空态“暂无数据，请调整筛选条件或新增”；错误“主数据加载失败，请重试”；无权限“当前身份只能查看主数据”。
- 响应式：≥1200px 筛选横排；768–1199px 筛选两行；<768px 筛选进入抽屉，表格最小宽度由列设置控制。
- 表格策略：编码/名称左固定，操作列右固定；地址、备注、联系人默认隐藏，可在列设置恢复。
- 优化：四类资料共用列表壳，减少旧系统各页操作位置差异。

## 入库新建/详情

- 页面目的：登记包数与总吨数，按 RK 规则生成单号并原子更新库存。
- 信息层级：单据头 → 明细行 → 合计/库存影响 → 确认。
- 文字线框：ProForm 头部；ProTable 明细；合计条；确认抽屉。
- 主操作：保存草稿、提交/审核、撤销/更正；单号只读预览 `RK-YYYYMMDD-####`。
- 四态文案：加载“正在加载入库资料…”；空态“暂无明细，请添加商品”；错误“保存失败，已保留已填写内容，请重试”；无权限“当前状态不可编辑”。
- 响应式：≥1200px 头部与合计双栏；768–1199px 合计置于明细下方；<768px 明细改为卡片行，确认栏底部固定。
- 表格策略：商品、包数、总吨数左固定；行操作右固定；备注/柜号在“更多信息”折叠区。
- 优化：不扫码、不按统一件重反算；差异在录入时提示并定位字段。

## 入库列表

- 页面目的：B1b-1 按单号、登记日期、原始状态、入账状态、供应商和仓库定位单据；XLSX导出见下方共用族，打印已延后，依赖积木报表配置。
- 信息层级：标题/登记入库 → 可展开组合筛选 → 包数/吨数/原始状态 → 详情。
- 文字线框：PageContainer；统一 QueryFilter；ProTable 列设置/选择/稳定分页；详情返回原筛选、页码和排序。
- 主操作：首屏唯一主按钮“登记入库”；行内“查看详情”；查询为普通按钮；不提供批量确认/撤销。
- 四态文案：加载骨架及“正在查询列表”读屏提示；空态“没有符合条件的记录，可调整筛选条件或重置后重试”；错误“列表加载失败，已停止展示旧数据”+重试；无权限“无权查看此列表”。
- 响应式：1280/1440 内容容器宽 100%、min-width 0；PageContainer 横向内边距 token.paddingLG；筛选按 1/2/3/4 列响应；超宽内容仅表内横滚，不承诺本批手机卡片布局。
- 表格策略：单号左固定，原始状态/操作右固定；包数、总吨数优先；20/50/100/200 行分页，表体最大高 480px；列显隐/顺序本机持久化；保留全部业务字段。
- 优化：URL 保存筛选/排序/页码；跨页选择保留、改筛选清空；历史入账标记仅显示“历史记录”，不推断历史状态；Enter 查询。

## 出库新建/详情

- 页面目的：创建 CK 计划，接收 PDA 扫码事实，Web 明确确认扣库存。
- 信息层级：计划头 → 计划/实扫对比 → 包级事实 → 库存影响。
- 文字线框：ProForm 计划头；ProDescriptions 摘要；事实表；确认抽屉。
- 主操作：创建/编辑计划、查看事实、冻结后确认出库；单号只读预览 `CK-YYYYMMDD-####`。
- 四态文案：加载“正在加载出库事实…”；空态“尚未收到扫码事实”；错误“出库事实加载失败，请重试”；无权限“PDA/小程序凭据不能确认出库”。
- 响应式：≥1200px 摘要与事实双栏；768–1199px 上下排列；<768px 包级事实卡片纵向排列，确认栏底部固定。
- 表格策略：条码/实重左固定；目录版本与 ERP 作业行可见；状态与操作右固定；当时规格、设备、原始正文进入事实详情抽屉。
- 优化：冻结不是出库；确认核对已扫事实而非当前目录，同单多目录版本正常显示；确认抽屉显示前后库存和包级实重，避免审核按钮承担两种语义。

## 出库列表

- 页面目的：B1b-1 按单号、建单日期、状态、客户、仓库、车牌追踪计划，分别展示计划与实扫包数/吨数。
- 信息层级：标题/新建计划 → 可展开组合筛选 → 单号/计划数量/状态 → 实扫及其他字段 → 详情。
- 文字线框：与入库同一 BusinessList/QueryFilter/ProTable；状态保留原值查询；详情返回原列表上下文。
- 主操作：首屏唯一主按钮“新建计划”；行内“查看详情”；不提供批量库存确认；XLSX导出见下方共用族，打印已延后，依赖积木报表配置。
- 四态文案：统一加载骨架；空态“没有符合条件的记录，可调整筛选条件或重置后重试”；错误“列表加载失败，已停止展示旧数据”+重试；无权限“无权查看此列表”。
- 响应式：1280/1440 内容宽 100%、min-width 0、横向内边距 token.paddingLG；筛选响应式展开/折叠；横滚仅发生于表格；本批不改 PDA/小程序。
- 表格策略：单号左固定，状态/操作右固定；计划与实扫数量分别保留列和四位吨数；表体最大高 480px，20/50/100/200 行；列显隐/顺序本机持久化。
- 优化：跨页选择保留、改筛选清空；Enter 查询，详情返回保留条件/页码/排序；未知值显示“状态待识别：原文”，不映射业务语义。

## PDA 扫码与补传

- 页面目的：常态断网按上次完整同步的本地目录采集成功事实，原版本/实重持久保存；回到有网处回传事实与刷新目录。
- 信息层级：原出库单/当前 ERP 作业行/本地目录版本/连接状态 → 扫码结果与实重 → 待回传、已回传、冲突及目录差异提示。
- 文字线框：单号及 ERP 商品；扫码焦点区；最近结果含目录规格/实重/版本；队列计数；版本与异常详情。
- 主操作：离线连续扫码、联网按原 UUID/正文补传、刷新目录、查看冲突；单明细默认当前行，多明细先选行；上传并刷新后原单续扫。
- 四态文案：加载“正在读取本地 v2 目录…”；空态“尚无扫码记录”；错误“本地 v2 未找到该码，上传并刷新目录后可在本单继续扫码”/“回传失败，事实仍在本机，可继续扫码”；无权限“当前设备不能提交此出库单”；成功“本机已记录，待回传”。
- 响应式：320–599dp 单列竖屏且主扫码区常驻；≥600dp 扫码区与记录区并列；横屏仍固定输入焦点和主操作。
- 列表策略：不用宽表；条码/当时重量/目录版本/同步状态固定显示；原正文在详情；旧事实不从当前缓存重新分配 ERP 行。
- 优化：本地同步版本 + 服务端接受历史版本事实；刷新失败仍用原完整本地版扫码；“该包基于 v2，当前目录 v3，重量 300→302kg；已按 300kg 接收”常驻记录详情，只提示、不改重/拒收/拦冻结；版本不存在/被撤销等异常进可见冲突队列，原事实不丢弃。

## 小程序只读查询

- 页面目的：现场快速查询出库单与库存，不承担扫码事实、入库或库存写入。
- 信息层级：关键词/状态筛选 → 单据卡片 → 只读详情与库存摘要。
- 文字线框：顶部搜索栏；筛选项；分页列表卡片；单据详情；返回列表。
- 主操作：搜索、打开详情、返回原列表位置；无编辑、扫码、审核或确认按钮。
- 四态文案：加载“正在查询单据…”；空态“没有找到符合条件的单据”；错误“查询失败，筛选条件已保留，请重试”；无权限“当前身份无权查看此单据”。
- 响应式：320–430px 单列卡片；≥431px 保持单列并扩大内容留白；安全区内操作按钮全宽或至少 44px 高。
- 列表策略：不使用横向表格；单号/客户/状态固定显示，时间与重量次级显示，操作为整卡进入详情。
- 优化：详情返回保留关键词、页码、已加载结果和滚动位置，只刷新当前查询；减少重新翻页和定位。

## 库存查询/调整

- 页面目的：B1b-1 按 ERP 商品/仓库查库存，保留既有最近流水及原因必填的调整抽屉；不改变库存逻辑。
- 信息层级：固定“库存口径：ERP 商品” → 商品/仓库筛选 → 当前筛选范围汇总（含全部分页） → 库存行 → 最近流水。
- 文字线框：统一 BusinessList/QueryFilter/ProTable；商品名称和包数/吨数优先；调整抽屉保留原前后值/原因/幂等语义；无来源页签。
- 主操作：查询、行内“调整库存”、查看既有流水依据；调整成功刷新新旧查询缓存；XLSX导出见共用族。
- 四态文案：统一加载骨架；空态“没有符合条件的记录，可调整筛选条件或重置后重试”；错误“列表加载失败，已停止展示旧数据”+重试；无权限“无权查看此列表”；错误/无权限均不残留小计。
- 响应式：1280/1440 内容宽 100%、min-width 0、横向内边距 token.paddingLG；筛选按断点折行；库存/流水仅表内横滚；不在本批改为手机卡片。
- 表格策略：商品名称左固定、调整操作右固定；包数/四位吨数前置；编码和仓库可查；表体最大高 480px；分页20/50/100/200；列设置本机持久化。
- 优化：一次最多取 200 库存行，小计仍来自相同筛选的全部有效 ERP 行；SPEC/未归属无入口或占位；未归属只记诊断日志；逐行流水筛选仍待后续。

## B1c 条码目录与设备交接（B1c-1/2 本地已验证）

- 页面目的：Web 手动上传有效条码全量快照，查询当前/历史规格与实重；只服务扫码，不是库存、入库或报表入口。
- 信息层级：当前版/条数及用途说明 → 门禁原因 → 上传校验/差异 → 版本历史；设备/清单/收妥/待归属/旧请求水位常驻；只显示已上报结果，不假称实时。
- 文字线框：PageContainer 当前版；ProForm/Upload 全量文件与编码；候选出现后差异与发布前置；ProTable 固定基线差异；ProDescriptions 历史抽屉，支持刷新后继续核对候选。
- 主操作：当前目录首屏“上传全量文件”，差异阶段仅“发布整版”为主按钮；一次发布，不逐条确认消失码；同内容显示“与第 N 版内容一致”默认不建版，二次确认可重建，历史版只能作为后继版重新发布。
- 四态文案：加载“正在校验完整目录，当前版本仍可用…”；空态“当前版本无有效条码”/“该版未找到该条码”；错误“发布失败，当前目录未变，请重试”（提交结果未知时改“正在核验发布结果”，不谎称未变）；无权限“仅 Web 登录用户可发布目录”。
- 响应式：≥1200px 内容宽 100% 且 max-width 1440px；768–1199px 差异摘要换行、抽屉宽 min(720px,100%)；<768px 卡片与全宽详情；1440/1280 均无页面横滚，间距沿用 token。
- 表格策略：差异表条码左固定，规格可换行；旧→新重量标 kg/四位吨数；差异无行操作列，采用游标前后页，不显示库存合计；交接表设备左固定、操作右固定，明细抽屉最大 960px。出库事实表显示取重目录版本；历史 API 独立提供 ERP 行和差异提示。
- 优化：移除提示“本版移除（已出库）；历史版本事实仍可回传，库存仍由 Web 确认”；零条快照明显显示“本版移除全部”；坏行整版不发布；发布门禁原因常驻，不提供绕过按钮；M71 隔离包刷新/断网/同单混版已验；未收妥按原单一次批量确认，真实现场队列未验。

## 盘点

- 页面目的：创建库存快照、录入实盘、处理差异并回写库存。
- 信息层级：盘点头 → 系统库存/实盘输入 → 差异 → 回写或作废。
- 文字线框：ProForm 仓库/日期；可编辑明细表；差异汇总；确认抽屉。
- 主操作：加载库存、确认盘点、差异回写、作废。
- 四态文案：加载“正在生成盘点快照…”；空态“该仓库没有可盘点库存”；错误“盘点数据加载失败，请重试”；无权限“当前身份不能回写盘点差异”。
- 响应式：≥1200px 明细表与差异摘要双栏；768–1199px 摘要置底；<768px 逐行卡片输入，保持键盘顺序。
- 表格策略：商品/系统数/实盘数左固定；差异与操作右固定；备注进入行展开。
- 优化：差异同表即时出现，减少旧系统跨页手算；差异放行本轮不做。

## 统计报表

- 页面目的：提供月度汇总、周转率、出入库明细和库龄分析。
- 信息层级：周期/固定 ERP 库存口径 → 指标摘要 → ProTable/图表 → 导出/下钻。
- 文字线框：筛选栏；指标条；表格/图表；导出按钮；明细抽屉。
- 主操作：查询、排序、导出、下钻；ERP 用途边界始终可见，无目录来源切换。
- 四态文案：加载“正在计算报表…”；空态“该口径暂无数据”；错误“报表计算失败，请重试”；无权限“当前身份无权查看此报表”。
- 响应式：≥1200px 指标和图表双栏；768–1199px 图表上下排列；<768px 图表先摘要后明细，禁止页面级横滚。
- 表格策略：指标列与 ERP 商品列左固定；导出列顺序与屏幕 schema 一致；下钻操作右固定。
- 优化：只统计 ERP 单据和库存，扫码目录不参与；表格字段顺序与XLSX导出一致；打印另按积木旧件验收；公式和截止日可见。

## 系统配置

- 页面目的：维护数据字典、系统参数和 RK/CK 单据编号规则。
- 信息层级：配置分组 → 当前值/新值 → 影响范围 → 保存审计。
- 文字线框：Tabs 分组；ProTable/ProForm；编号规则预览；保存确认。
- 主操作：维护字典项、保存参数、预览下一个 RK/CK 单号。
- 四态文案：加载“正在加载配置…”；空态“暂无配置项”；错误“配置加载失败，请重试”；无权限“当前身份只能查看配置”。
- 响应式：≥1200px 分组与编辑双栏；768–1199px 编辑置于列表下方；<768px Tabs 改为下拉选择。
- 表格策略：配置键/名称左固定；启停/编辑右固定；原值、新值和生效范围在详情抽屉展示。
- 优化：规则保存前展示下一个结果；入库 `RK-YYYYMMDD-####`、出库 `CK-YYYYMMDD-####`，本轮已定不再询问。

## 系统监控

- 页面目的：B1b-1 查询完整操作日志并查看前后值；在线会话/强制下线仍未实现，不混入本批。
- 信息层级：时间/操作类型/业务对象/请求编号筛选 → 完整历史分页 → 单条操作前后值详情。
- 文字线框：统一 BusinessList/QueryFilter/ProTable；只传轻量列表字段；640px 抽屉按需加载 before/after；JSON 换行。
- 主操作：查询、行内“查看详情”、复制请求编号；Esc 关闭抽屉；XLSX导出见共用族，无撤销/回滚按钮。
- 四态文案：统一加载骨架；空态“没有符合条件的记录，可调整筛选条件或重置后重试”；错误“列表加载失败，已停止展示旧数据”+重试；无权限“无权查看此列表”。
- 响应式：1280/1440 内容宽 100%、min-width 0、横向内边距 token.paddingLG；筛选按断点折行；抽屉受视口约束；JSON 不导致页面横滚。
- 表格策略：动作左固定、详情操作右固定；对象/时间/操作者/请求编号保留；前后值不随列表全量传输；表体最大高 480px，20/50/100/200 行分页。
- 优化：取消最近 100 条截断，已验证 240 条完整分页及万级查询；原始 action/traceId 保留可追溯性；无结果码字段时不伪造“成功/失败”筛选。

## 消息中心

- 页面目的：展示与单据/库存直接相关的通知、提醒和预警。
- 信息层级：未读筛选 → 消息列表 → 详情/关联单据。
- 文字线框：未读计数；ProTable；详情抽屉；跳转按钮。
- 主操作：打开消息、标记已读、跳转单据；不做聊天和公告编辑。
- 四态文案：加载“正在加载消息…”；空态“暂无消息”；错误“消息加载失败，请重试”；无权限“当前身份不能查看消息”。
- 响应式：≥1200px 列表与详情双栏；768–1199px 详情抽屉；<768px 列表卡片化，跳转按钮置底。
- 表格策略：时间/级别/标题左固定；跳转/已读右固定；正文在抽屉显示。
- 优化：从消息到目标单据保持 2 步以内；只保留可解释的业务消息。

## 四列表 XLSX 导出（B1b-2）

- 页面目的：只导出当前入库/出库/ERP库存/操作日志列表；不提供移动端导出或打印入口。
- 信息层级：三种范围及条数 → 可见字段顺序 → 生成进度 → 任务页别/范围/时间 → 范围合计/前20条预览 → 下载。
- 文字线框：列表工具栏次按钮“导出”；右侧非模态Drawer；可关闭继续查询、重新打开看进度。
- 主操作：未完成时“生成XLSX”，完成后“下载XLSX”；生成按钮降次级；运行中可取消，第二任务提示“已有导出在进行”。
- 四态文案：加载“正在生成 X / N 条”；空态“此范围没有可导出记录”；错误“导出失败，未提供部分文件。请重试或提供任务编号”；无权限继承列表403，PDA/小程序403。
- 断点/宽度：1440和1280均640px抽屉，最大100vw；可Esc关闭；表格横滚只在抽屉内，页面横滚0。
- 表格策略：保留屏幕数据列实际顺序/显隐，去除操作与选择列；文件表头冻结，列宽按字段定义，吨数四位/数字真实类型/上海时间。
- 恢复：失败/取消不下载半份；保留筛选与选择，视图变化时先刷新核对；文件24小时可重下，重启中的任务提示重新生成；跨页选择上限5000、全量上限100万均明示。
- 优化：默认范围从打开到下载3次点击；四页共用同一面板和字段定义；实际逐格/性能/WPS证据见ACCEPTANCE，Microsoft Excel未实测。

## 单据纠错与终结（B2a）

- 页面目的：在原详情纠正误确认或作废未入账单；不涉及实物退货、更正或原单重开。
- 信息层级：原状态/单号→可操作性或阻断记录→原确认流水及库存前后值→原因→终结证据。
- 文字线框：原详情Card“纠错与终结”→560px Drawer核对补偿→原因表单→终态Alert；原明细与事实始终保留。
- 主操作：次级危险按钮“核对撤销误确认/核对并作废”；抽屉唯一主按钮“确认撤销入账/确认作废”；终态无确认/编辑/扫码入口，原号不复用。
- 四态：加载骨架；历史/不可用“本单暂不能撤销或作废”并列原因；错误保留原因与幂等请求，可重试/刷新预览；无权限“仅Web可处理单据终结”。
- 断点/宽度：1440/1280均560px抽屉，受Drawer视口约束；不改默认密度。逐商品ProDescriptions单列显示前值/delta/后值，不增加横向大表。
- 依赖：同仓商品后续流水显示流水号/操作ID/对象；已下发、冻结、事实或交接存在则不展示作废按钮；不以空表推断现场无队列。
- 恢复与边界：同正文重试沿用幂等键；刷新不清原因，用户重新核对后提交；已成功终结显示原因、时间、原操作与补偿ID。历史单据只读，已扫出库作废留B2b。
