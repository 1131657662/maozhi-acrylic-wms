# 打印集成规范（PRINT_SPEC）

## 1. 模式

打印不由本系统排版，而是**调用积木报表**生成 PDF。本系统只做三件事：

1. 保存打印配置（受控服务别名、报表ID、密钥引用、参数名）；
2. 服务端代理调用，流式返回 PDF；
3. 提供打印入口（列表行、详情页），按单据类型选择对应模板。

版式与字段由积木模板负责；必须对齐新单数据契约并通过PDF/实打验收，复用模板不自动保证与老系统一致。当前仅disabled占位，配置表/代理均需要新增服务能力。

## 2. 打印配置表

`print_templates`：

| 字段 | 说明 |
|---|---|
| id | 主键 |
| kind | inbound / outbound / outbound_overlay（套打） |
| name | 显示名，如「入库单 A4」 |
| service_alias | 服务端受控连接别名，真实地址仅由部署配置保存 |
| report_code | 积木报表 ID |
| secret_ref | 服务端密钥引用（可空），不保存明文到业务审计 |
| param_name | 传给积木的参数名，如 orderNo / receiptNo |
| output_format | 本批固定pdf，不开放excel或盘点模板 |
| enabled | 启用 |
| updated_at / updated_by | 审计 |

规则：
- 同一kind只允许一个enabled模板：启用槽生成列+唯一约束、事务锁和版本校验，不能只前端限制；
- token 只存服务端，不下发浏览器；
- 修改配置写脱敏前后值审计；secret_ref/token只记是否已配置与凭证版本，禁止通用JSON审计泄密；读取仅返回掩码/hasCredential。

## 3. 配置页

路径：/settings/print（系统配置下）

列表：类型、名称、服务别名、报表ID、参数名、固定PDF格式、启用、操作；真实地址/token不返回浏览器。

操作：
- 新增/编辑抽屉：kind、name、service_alias、report_code、param_name及启用；凭证由服务端密钥配置管理；
- **测试打印**：输入一个真实单号 → 调用一次 → 直接预览 PDF；
- 停用/启用；
- 服务别名或报表ID变更时二次确认；配置版本递增，旧生成请求仍绑定原版本。

## 4. 调用链

```
Web 点击打印
→ POST /api/v1/print/requests（kind、businessId、documentVersion、幂等键）
→ API 查配置（enabled）
→ 服务端解析受控服务别名/密钥并构造积木请求（URL、凭证不入日志）
→ 绑定模板版本/单据数据快照，服务端请求去重
→ 流式接收 PDF
→ 校验响应为 PDF（Content-Type / 魔数 %PDF-）
→ 返回带 Content-Disposition 的流
→ 浏览器下载/预览
```

要求：
- 30 秒超时；
- 积木返回非 PDF 或报错 → 502，提示原因，不产生空文件；
- 同一单据数据版本+kind+模板版本生成请求去重，服务端唯一键/请求状态复用，跨页/掉响应重试返回同一结果；前端节流仅防连点；
- 不落盘长期保存（可选临时文件 + 24h 清理）。

## 5. 打印入口与模板映射

| 页面 | 入口 | kind |
|---|---|---|
| 入库列表行 | 行内可见「打印」位（最多三个入口） | inbound |
| 入库详情 | 底部操作条「打印」 | inbound |
| 出库列表行 | 行内可见「打印」位（套打在更多） | outbound |
| 出库详情 | 底部操作条「打印」+「套打」 | outbound / outbound_overlay |
| 盘点详情 | 导出（不做积木打印） | — |

未接入服务时：disabled + tooltip「待接入积木报表」；接入后未配置kind时才用「未配置打印模板」。占位是WEB_UX_SPEC隐藏不可用动作规则的例外。

## 6. 打印状态与版本

| 场景 | 表现 |
|---|---|
| 已撤销/已作废单据 | 允许打印，PDF实际内容由模板加准确「已撤销确认/已作废」水印，前端提示不能代替 |
| 更正过的单据 | 打印时提示「已更正，建议打印最新版」，PDF绑定请求确定的数据版本，包含原量/有效量/累计差额及最近更正；不得生成中途换成另一版本 |
| 部分发货出库单 | 打印当前已发量，注明「部分发货」 |

## 7. 安全

- 积木真实地址与token仅服务端可见；服务别名白名单限定协议/主机/端口，禁任意URL与重定向跳转，阻止元数据/非白名单内网请求，超时/响应体积设常量上限；
- 打印接口需登录且限 Web 渠道；
- 禁止前端直接请求积木域名（会泄露 token 与内网地址）；
- 日志记录：谁在何时打印了哪张单（不记录 PDF 内容）。

## 8. 验收

1. 配置页保存后，测试打印能返回可打开的 PDF；
2. 三模板分别提供单页/跨页、更正/撤销、部分发货样本，对字段/页码/合计/水印与旧样件叠图及实打校验；实际模板参数/旧PDF为后续集成输入，不在本轮宣称通过；
3. 积木不可用时页面提示明确，无空文件；
4. 浏览器网络面板中不出现 token 或积木内网地址；
5. 未配置模板时按钮禁用且有提示；
6. 作废单打印带作废标识；
7. 打印日志可查。

## 9. 边界

| 情况 | 处理 |
|---|---|
| 积木超时 | 502 + 提示稍后重试 |
| 返回 HTML 错误页 | 判定非 PDF，报错不下载 |
| 报表 ID 错误 | 积木侧报错 → 502 + 中文原因，原始状态码仅审计原始数据区 |
| 套打纸张 | 模板固定 A4 纵向，打印时不得缩放 |
| 多模板 | 同 kind 只有一个启用，历史模板可停用保留 |
