# 打印集成规范（PRINT_SPEC）

## 1. 模式

打印不由本系统排版，而是**调用积木报表**生成 PDF。本系统只做三件事：

1. 保存打印配置（积木地址、报表 ID、token、参数名）；
2. 服务端代理调用，流式返回 PDF；
3. 提供打印入口（列表行、详情页），按单据类型选择对应模板。

版式与字段由积木模板负责，因此与老系统天然一致。

## 2. 打印配置表

`print_templates`：

| 字段 | 说明 |
|---|---|
| id | 主键 |
| kind | inbound / outbound / outbound_overlay（套打）/ stocktake |
| name | 显示名，如「入库单 A4」 |
| api_url | 积木导出接口地址 |
| report_code | 积木报表 ID |
| jimu_token | 积木 token（可空） |
| param_name | 传给积木的参数名，如 orderNo / receiptNo |
| output_format | pdf / excel |
| enabled | 启用 |
| updated_at / updated_by | 审计 |

规则：
- 同一 kind 只允许一个 enabled 模板；
- token 只存服务端，不下发浏览器；
- 修改配置写审计（前后值）。

## 3. 配置页

路径：/settings/print（系统配置下）

列表：类型、名称、积木地址、报表 ID、参数名、格式、启用、操作。

操作：
- 新增/编辑抽屉：五个字段 + 启用开关；
- **测试打印**：输入一个真实单号 → 调用一次 → 直接预览 PDF；
- 停用/启用；
- 地址或报表 ID 变更时要求二次确认（会影响所有打印）。

## 4. 调用链

```
Web 点击打印
→ GET /api/v1/print/:kind/:businessId
→ API 查配置（enabled）
→ 拼接积木请求：api_url?token=…&exportParams=[{reportId,exportType,queryParam:{<paramName>:<单号>}}]
→ 流式接收 PDF
→ 校验响应为 PDF（Content-Type / 魔数 %PDF-）
→ 返回带 Content-Disposition 的流
→ 浏览器下载/预览
```

要求：
- 30 秒超时；
- 积木返回非 PDF 或报错 → 502，提示原因，不产生空文件；
- 同一单号重复点击不重复生成（前端节流即可）；
- 不落盘长期保存（可选临时文件 + 24h 清理）。

## 5. 打印入口与模板映射

| 页面 | 入口 | kind |
|---|---|---|
| 入库列表行 | 「更多 → 打印」 | inbound |
| 入库详情 | 底部操作条「打印」 | inbound |
| 出库列表行 | 「更多 → 打印」 | outbound |
| 出库详情 | 底部操作条「打印」+「套打」 | outbound / outbound_overlay |
| 盘点详情 | 导出（不做积木打印） | — |

未配置对应 kind 时：按钮禁用，tooltip「未配置打印模板」。

## 6. 打印状态与版本

| 场景 | 表现 |
|---|---|
| 已撤销/已作废单据 | 允许打印，PDF 上加「作废」标识（由模板或前端提示） |
| 更正过的单据 | 打印时提示「已更正，建议打印最新版」，PDF 版本号由模板取最新 |
| 部分发货出库单 | 打印当前已发量，注明「部分发货」 |

## 7. 安全

- 积木地址与 token 仅服务端可见；
- 打印接口需登录且限 Web 渠道；
- 禁止前端直接请求积木域名（会泄露 token 与内网地址）；
- 日志记录：谁在何时打印了哪张单（不记录 PDF 内容）。

## 8. 验收

1. 配置页保存后，测试打印能返回可打开的 PDF；
2. 入库单、出库单、套打三种各打一张，与老系统同单号打印件叠图一致；
3. 积木不可用时页面提示明确，无空文件；
4. 浏览器网络面板中不出现 token 或积木内网地址；
5. 未配置模板时按钮禁用且有提示；
6. 作废单打印带作废标识；
7. 打印日志可查。

## 9. 边界

| 情况 | 处理 |
|---|---|
| 积木超时 | 502 + 提示稍后重试 |
| 返回 HTML 错误页 | 判定非 PDF，报错不下载 |
| 报表 ID 错误 | 积木侧报错 → 502 + 原始状态码 |
| 套打纸张 | 模板固定 A4 纵向，打印时不得缩放 |
| 多模板 | 同 kind 只有一个启用，历史模板可停用保留 |
