# 全局视觉与布局规范（VISUAL_SPEC）

> 页面规格定“有什么”，本文件定“长什么样、间距多少”。
> 所有页面共用本规范；与页面规格冲突时，以本文件为准（间距、字号、颜色）。

## 1. 页面骨架

```
┌ 侧栏 208px ┬ 内容区（padding 24） ─────────────┐
│            │ 页头：标题 20px + 主操作           │
│            │ 间距 16                          │
│            │ 筛选/工具条                       │
│            │ 间距 16                          │
│            │ 卡片 / 表格 / 图表                │
└────────────┴──────────────────────────────────┘
```

- 侧栏宽 208px，折叠后 64px；
- 内容区左右留白 24px，上下 24px；
- 多个卡片之间间距 16px；
- 页面不设最大宽度，宽屏自然铺满。

## 2. 间距刻度

只用四档：**4 / 8 / 16 / 24**。禁止 10、15、20 这类随手值。

| 场景 | 值 |
|---|---|
| 文字与图标 | 4 |
| 表格内元素 | 8 |
| 卡片内边距 | 16（小卡）/ 24（大卡） |
| 卡片之间、区块之间 | 16 |
| 页头与内容 | 16 |
| 内容与页脚/操作条 | 24 |

## 3. 字号与字重

| 用途 | 字号 / 行高 | 字重 |
|---|---|---|
| 页面标题 | 20 / 28 | 600 |
| 卡片标题 | 16 / 24 | 600 |
| 正文、表格 | 14 / 22 | 400 |
| 辅助说明、单位 | 12 / 20 | 400 |
| KPI 大数字 | 28 / 36 | 600 |

规则：
- 数字用等宽（tabular-nums），右对齐；
- 中文不用斜体、不加字间距；
- 一行最多两级字号，不在一行里混 3 种字号。

## 4. 颜色

| 用途 | 来源 |
|---|---|
| 主色 | `token.colorPrimary` |
| 成功 | `token.colorSuccess` |
| 警告 | `token.colorWarning` |
| 错误 | `token.colorError` |
| 边框 | `token.colorBorderSecondary` |
| 次要文字 | `token.colorTextSecondary` |

规则：
- 页面里不出现裸色值；
- 状态色只用于标签、圆点、左侧色条，不整行染色；
- 表格行悬停浅灰，选中浅蓝，不用彩色底。

## 5. 卡片

- 圆角 12px；
- 阴影 `0 1px 2px rgba(0,0,0,.04)`，不用重阴影；
- 边框 1px `colorBorderSecondary`；
- 内边距 16；
- 卡片标题 16px，右侧可放一个次要操作。

## 6. 表格

| 项 | 标准 |
|---|---|
| 行高 | 标准 44px，紧凑 36px |
| 表头 | 12px 次要色，不换行 |
| 单元格 | 14px，超出省略 + tooltip |
| 数字列 | 右对齐、等宽 |
| 操作列 | 右固定，最多 3 个入口 |
| 空态 | 插画或图标 + 一句说明 + 一个动作 |
| 加载 | 表内骨架，不整页白屏 |

## 7. 表单

- 标签在上，控件在下，标签与控件间距 4；
- 控件高度 32（标准）/ 40（大）；
- 两列布局，列间距 16，行间距 16；
- 必填项在标签前加红色星号；
- 错误信息在控件下方，12px 红色；
- 一组字段不超过 8 个；超出分组（卡片或折叠）。

## 8. 按钮

| 类型 | 用在哪 |
|---|---|
| 主按钮（实心） | 每页最多 1 个 |
| 次按钮（描边） | 工具栏 |
| 文字按钮 | 行内操作 |
| 危险按钮 | 只在「更多」菜单里，红色文字 |

- 按钮高度 32；
- 两个按钮间距 8；
- 危险按钮不与主按钮并排。

## 9. 响应式

| 宽度 | 规则 |
|---|---|
| ≥1440 | 完整布局，侧栏展开 |
| 1280–1439 | 侧栏展开，卡片间距不变，表格横向滚动 |
| 1024–1279 | 侧栏可折叠，两列变一列 |
| <1024 | 只保证可操作，不追求美观 |

- 任何宽度下页面不出现整体横向滚动，只有表格内部滚动；
- 断点用 AntD 默认：`xl 1200`、`lg 992`。

## 10. 状态与反馈

| 状态 | 表现 |
|---|---|
| 加载 | 骨架或小 spin，保留页面结构 |
| 空 | 一句说明 + 一个动作 |
| 错误 | 中文原因 + 重试 |
| 禁用 | 降低透明度，鼠标禁止，附 tooltip 说明原因 |
| 成功 | 顶部轻提示，2 秒消失 |

## 11. 三个页面模板

### 列表页

```
页头（标题 + 主操作）
筛选行（快捷条件 + 筛选按钮）
工具栏（批量/导出/列设置）
表格
分页
```

### 详情页

```
页头（单号 + 状态标签 + 主操作）
摘要卡（关键信息 4–6 项）
明细表
时间线 / 审计
底部固定操作条
```

### 看板页

```
时间范围
KPI 卡 ×4
图表 ×2（一主一次）
排行榜 / 明细表
```

## 12. 验收

1. 截图对比：同类型页面（两个列表、两个详情）在 1440 下骨架一致；
2. 间距抽查：随机 5 处，值只能是 4/8/16/24；
3. 字号抽查：页面内不超过 4 种字号；
4. 颜色抽查：页面无裸色值；
5. 1280 与 1024 下无页面横向滚动；
6. 表格行高统一，密集模式可切换。
