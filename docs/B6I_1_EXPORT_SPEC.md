# B6i-1 通用导出键集分页

本批以 `5c32d3c` 为起点，分支 `codex/b6i-1-keyset-export`。用户于 2026-11-15 授权：从库存扩大到库存、操作记录、入库、出库四类 Web 列表导出；三笔提交（测量基线、实现、验收）后停止，不合并、不推送。

## 范围与不变量

- 只改变导出的读取与批次推进路径。普通列表分页、接口、UI、现有性能断言与所有上限不变。
- 保留请求筛选和排序。库存以业务排序字段及 `(warehouse_code, product_code)` 唯一兜底；有效库存固定 `source_del_flag=0`。
- 操作记录保留原业务排序及 `record_id`（含 event/attempt 前缀）唯一兜底，包括字符串 ID 的既有字典序，不能改成数字序。
- 入出库 `document_summary` 一行仍是主单，按请求排序（单号排序为单号＋主单 ID）推进；`matched_lines` 在每个主单内按行 ID 展开，最终为单号/主单顺序＋行 ID。不将明细 ID 错作主单游标，也不改变粒度。
- 游标值取自数据库原始排序表达式，避免中文显示映射、重量换算或时间格式化改变比较值。NULL、重复值、升降序均保持 MySQL 原顺序。
- 生成、预检和选中命中行计数均不发 OFFSET SQL；当前页核对需要跳过前页时也沿键集前进。只在服务内部传游标，不新增客户端参数。
- 同一次生成保持 READ ONLY / REPEATABLE READ；保留 viewToken、rowToken、409 冲突、100000 上限及 100001 返回 422；取消/失败不发布半文件。
- 报表沿用 B7a-3 原快照重放，仅适配公共导出批次契约，不改变报表查询、计算或快照规则。

## 索引与验证

迁移 026 仅包含 EXPLAIN/EXPLAIN ANALYZE 实测缺失且试验确认有效的索引。先在随机本地测试库试验候选，再写迁移并在新测试库应用；不预建全部可排序列索引。down 检查相关业务表，非空拒绝且迁移状态/索引不变。

本轮实测结论：没有需要进入迁移的索引。库存候选 `(source_del_flag,product_code,warehouse_code)` 在有序连接下约3.69ms，现有 `stock_product_fk` 约3.38ms；不保留候选。入出库现有单号索引已作范围扫描，操作记录先从现有覆盖索引选键，再主键读取正文。故不创建/应用026，不伪造空迁移或往返/down通过记录；下一编号仍为026。导出审计批次为2000，其余为1000，均为服务内部常量，不改变列表分页或导出上限。该判断和证据同步台账。

库存导出专用读取加入当前批次商品范围（原仓库/商品条件的必要条件），复用 `outbound_product_fk`；普通列表不启用该参数。库存商品/仓库排序仅在导出使用已验证的索引及连接顺序提示，其余排序保留通用键集逻辑。

实测目标：库存 100000 行 XLSX 总生成时间 ≤20s，SQL 等待占比 <50%；其他三类同口径披露改前/改后数值，不修改既有断言。

验证覆盖四类 100000 行逐字段 hash、行数、列顺序；入出库另测命中明细；升降序、NULL、重复值、不同列表页大小/批次大小；100001 上限、取消清理、快照期间并发列表读取及写入不被表锁阻塞；026 往返与回退守卫。

上述迁移验证在确有026时执行；本轮没有迁移，标为不适用，不以已有迁移测试替代。原025及以前的完整回归仍运行。

## 测量口径

`npx tsx scripts/b6i/measure.ts baseline|after` 使用全新随机 `maozhi_test_*` 库，结束销毁，仅合成数据。四类各 100000 行；入出库各 100000 主单、200000 有效明细及 100000 软删明细。操作记录时间固定，确保前后可复现。

总耗时从 generateSnapshot 开始到 XLSX writer.finish 完成（含当前页核对、SQL、数据投影及文件压缩）。SQL 等待使用同一异步上下文内 Database.all 的 await 墙钟累计，包括数据库执行、网络/驱动、连接等待，不冒称纯数据库 CPU。EXPLAIN ANALYZE 另列数据库执行时间。hash 对导出数据行的有序、类型化单元格 JSON 计算 SHA-256；列头单独比较，各列另有 hash；不把 ZIP 时间戳或文件字节 hash 当内容一致性。

原始 JSON、XLSX、SQL 慢样本和执行计划保存 `.local/evidence/b6i-1/`（不进 Git）；可重跑脚本入 Git。性能运行串行，不与构建/全量测试并发；记录环境与噪声限制。历史 B6i 测量保留，新的同夹具前后对照不覆盖历史数据。
