# 全站体验标准与文档审计（UX_STANDARDS）

本文件是 11 份页面规格的**横向约束**：文案、格式、图标、配置、操作舒适度。
各页面规格与本文件冲突时，以本文件为准。

## 1. 三条总原则

1. **用户看到的是业务语言，不是数据库语言**：不出现 `success`、`pending`、`open`、`frozen`、`audited`、UUID、内部 ID。
2. **不硬编码**：颜色、阈值、文案、格式、分页、超时全部来自 token / 常量 / 枚举。
3. **操作要顺，不要炫**：每一步都可返回、可取消、不丢输入；动画只用于反馈，不用于装饰。

## 2. 文案映射（禁止直接显示库值）

### 2.1 单据状态

| 库值 | 显示 |
|---|---|
| pending | 待确认 |
| confirmed | 已入账（入库）/ 已出库（出库） |
| open | 计划中 |
| frozen | 待确认（已扫码） |
| partially_shipped | 部分发货 |
| short_closed | 已短关 |
| reversed | 已撤销 |
| voided | 已作废 |
| audited（历史导入） | 历史单据 |
| completed | 已完成 |
| cancelled | 已取消 |

### 2.2 盘点状态

counting → 盘点中；completed → 已完成；voided → 已作废。

### 2.3 操作结果

| 库值 | 显示 |
|---|---|
| success / ok | 完成 |
| failed / error | 失败 |
| conflict | 冲突 |
| pending | 处理中 |

### 2.4 流水类型

inbound → 入库；outbound → 出库；check → 盘点；import → 导入；
stock.adjust → 库存调整；inbound.reverse → 入库撤销；outbound.reverse → 出库撤销；
stock.correct → 更正；stocktake.post → 盘点回写。

### 2.5 渠道

web → 网页端；pda → 手持终端；miniapp → 小程序。

### 2.6 未知值

统一显示「未识别」，**不显示原始值**；需要排查时在操作记录里查看（审计页保留原值）。

### 2.7 空值

统一显示「—」，不显示 null / undefined / 空白。

## 3. 数值与日期格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 吨 | 4 位小数 | 72.0000 吨 |
| 千克 | 3 位小数 | 302.000 kg |
| 包数 | 整数 | 240 包 |
| 百分比 | 1 位小数 | 18.0% |
| 日期时间 | YYYY-MM-DD HH:mm | 2026-11-09 10:12 |
| 日期 | YYYY-MM-DD | 2026-11-09 |
| 时长 | 中文 | 2 小时 15 分钟 |
| 负数 | 前置减号，红色 | −2 包 |

规则：数字右对齐、等宽字体；单位用 12px 灰字紧跟在数字后。

## 4. 图标

1. 页面标题左侧统一 **16px 线性 SVG 图标**（与左侧菜单图标同族），不放大、不加底色；2. 状态标签用「图标 + 文字」，不只靠颜色区分；3. 图标来源统一：`@ant-design/icons`，不自绘混搭、不用 emoji；4. 按钮内图标与文字间距 4px，纯图标按钮必须有 tooltip。

## 5. 不硬编码与配置清单

| 类别 | 要求 | 存放位置 |
|---|---|---|
| 颜色 | 只用 theme token；图表色也在主题里定义 | `app.tsx` token + `chartTheme.ts` |
| 状态/类型/原因 | 枚举 + 中文标签成对定义，前后端共用 | `packages/contracts` |
| 阈值（差异 10%、50 包、超时 7 天、锁仓 24 小时、目录 30 天、库龄 90 天） | 常量表，不散落页面 | `packages/contracts/constants.ts` |
| 分页（50/100/200）、缓存 TTL（30s）、请求超时、导出上限（10 万行） | 常量 | 同上 |
| 文案（空态、错误、确认） | 集中文案表 | `apps/web/src/text.ts` |
| 导出文件名 | 模板常量 | 同上 |
| 表名/字段名 | 只出现在数据层 | — |

验收方式：全局搜索页面代码，出现裸颜色值、裸阈值、裸状态字符串即为不合格。

## 6. 操作舒适度与流转

### 6.1 步骤预算

| 动作 | 上限 |
|---|---|
| 新建入库 / 出库 | ≤ 2 屏 |
| 确认入账 / 出库 | 1 次点击 + 1 次确认 |
| 更正 | ≤ 2 步（打开 → 填 → 确认） |
| 查一张单 | ≤ 2 步（搜索 → 打开） |
| 盘点一仓 | 建单 → 数 → 填 → 回写，4 步 |

### 6.2 不打断

- 抽屉/弹窗打开不改变页面滚动位置；
- 列表加载只做表内 loading，不整页闪白；
- 小于 300ms 的请求不显示 loading（避免闪烁），超过显示骨架；
- 提交失败保留输入与滚动位置；
- 任何抽屉支持 Esc 关闭，关闭后焦点回到触发按钮。

### 6.3 防误触

- 危险操作与主操作不并排，间距 ≥ 8px；
- 危险操作二次确认文案写明后果与受影响单号；
- 可逆操作（撤销一笔、清空选择）优先给「撤销」toast，而不是弹窗确认。

### 6.4 键盘与焦点

- Enter 提交/下一行，Esc 关闭，Tab 顺序符合视觉顺序；
- `/` 聚焦搜索框；
- 表格行选中后 Enter 打开详情；
- 弹窗打开聚焦第一个输入框。

### 6.5 空态与错误

- 空态：一句说明 + 一个动作（如「暂无入库单，去登记」）；
- 错误：说清原因 + 重试按钮，保留筛选；
- 403：说明无权限，不显示半截数据。

## 7. 跨文档审计发现（需修订）

| # | 问题 | 影响文档 | 修订 |
|---|---|---|---|
| 1 | 状态直接用库值（open/frozen/confirmed 等） | WEB_UX_SPEC、STOCKTAKE_SPEC、OPS | 全部改为中文映射，库值只出现在数据层 |
| 2 | 阈值散落（10%、50 包、7 天、24 小时、30 天、90 天） | STOCKTAKE、CATALOG、OPS、REPORT | 收敛到 constants.ts |
| 3 | 图表颜色写死 #105957 / #8aa3a0 | WORKBENCH、REPORTS | 移到 chartTheme token |
| 4 | 导出文件名模板各页各写 | REPORTS、AUDIT、STOCK | 统一模板常量 |
| 5 | 术语混用「ERP / 老系统 / 历史导入」 | 多份 | 统一：老系统（历史导入） |
| 6 | 打印占位描述重复且不一致 | 多份 | 统一为「打印（待接入）」共用组件 |
| 7 | 空态/错误文案各页自拟 | 多份 | 收敛到 text.ts，按场景复用 |
| 8 | 查询抽屉、列设置、保存视图在 4 份文档重复描述 | WEB_UX、STOCK、REPORTS、CATALOG | 只在 WEB_UX_SPEC 定义，其余引用 |
| 9 | 页面标题图标未定义 | 全部页面 | 统一 16px 线性图标 |
| 10 | 操作记录显示 trace_id 前 8 位（技术值） | AUDIT | 显示为「追踪号」可复制，不默认展示原文 |
| 11 | 库存页「来源」列可能显示 source_kind 原值 | STOCK、MASTER | 映射为 历史导入 / 本地新建 |
| 12 | 报表不可验证原因可能露出英文字段 | REPORTS | 原因文案中文映射 |

### 图表主题（chartTheme.ts）

```ts
export const chartTheme = {
  inbound: tokens.colorPrimary,      // #105957
  outbound: '#8aa3a0',
  grid: tokens.colorBorderSecondary,
  text: tokens.colorTextSecondary,
  fontSize: 12,
  tooltipBg: tokens.colorBgContainer,
};
```

页面与图表组件禁止出现裸色值；改色只改 token 或此文件。

## 10. 评审清单（每页验收时逐条打勾）

- [ ] 页面上没有任何英文库值、UUID、内部 ID
- [ ] 状态、类型、原因、渠道、结果全部中文且与映射表一致
- [ ] 空值显示「—」，未知值显示「未识别」
- [ ] 吨 4 位、千克 3 位、包整数、时间到分钟
- [ ] 颜色只用 token，页面无裸色值
- [ ] 阈值来自常量，页面无裸数字
- [ ] 页面标题带 16px 线性图标
- [ ] 危险操作不与主操作并排，且二次确认写明后果
- [ ] 抽屉 Esc 可关，关闭后焦点回触发按钮
- [ ] 空态有说明 + 动作；错误有原因 + 重试
- [ ] 加载不造成整页闪白或位置跳动
- [ ] 勾选/批量切换表格零位移
- [ ] 1440/1280 无页面横向滚动
- [ ] 键盘可完成主流程（Enter/Tab/Esc）
