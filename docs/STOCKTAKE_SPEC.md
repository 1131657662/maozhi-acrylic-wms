# 库存盘点规范（STOCKTAKE_SPEC）

> 本文档中的状态、类型、结果等库值仅作实现标识；界面显示必须按 docs/UX_STANDARDS.md 映射为中文。

## 1. 定位

盘点就干一件事：**数一遍，把账改对**。不做多余流程。

参照 SAP 实物盘点（建单 → 录入 → 差异过账）与旧 Vue 版字段，按单用户单仓（主仓约 59 行货）的实际规模裁剪。

## 2. 实际操作长什么样

```
① 新建盘点 → 选主仓 → 明盘 → 确定（59 行快照）
② 「导出空白盘点表」→ 打一张纸带去仓库（盲盘时表上不含系统数）
③ 按纸上的商品逐个数包数，写在纸上
④ 回来按行填入实盘包数（吨数自动折算）
⑤ 点「只看差异」复核 → 确认回写
```

十分钟能做完一仓。

## 3. 列表页

页头：库存盘点 + [新建盘点]

筛选：仓库、状态（进行中 / 已完成 / 已作废）

列表列：盘点单号、仓库、状态、进度（已盘 42/59）、差异（3 行，盈 1 亏 2）、锁仓时长、创建时间、操作。

行操作：
- 进行中：继续盘点、更多（作废、导出空白表、导出结果）
- 已完成：查看、导出
- 已作废：查看

锁仓时长超过 24 小时标红，提示「盘点未结束，该仓无法确认出入库」。

## 4. 新建盘点

抽屉四项：

| 字段 | 规则 |
|---|---|
| 仓库 | 必填 |
| 范围 | 全部商品（默认）/ 指定商品（多选） |
| 模式 | 明盘（默认）/ 盲盘 |
| 备注 | 选填 |

建单前提示（不阻断）：
- 该仓有 N 张已冻结未确认的出库单 → 「建议先确认，否则已离场的货会被盘成盘亏」
- 该仓有未补传的 PDA 事实 → 「建议先补传」

规则：
1. 同仓同时只能有一张进行中盘点；
2. 创建即生成不可变快照并锁仓；
3. **快照只包含有库存的商品行**（包数 > 0 或吨数 > 0）；零库存商品不列，现场发现即走「盘盈一行」；
4. 范围确定后不可改；不提供“刷新快照”，快照不对只能作废重建；
5. 不做按分类范围（当前无分类数据）。

### 录入规则

1. **只填包数**；吨数默认按「系统吨数 ÷ 系统包数 × 实盘包数」折算，可手工覆盖。
2. 系统包数为 0 的行（盘盈行）无法折算，**吨数必填**。
3. 空值 = 未盘，不当作 0；未盘行不允许回写。
4. 明盘实时显示差异；盲盘在点「核对差异」后才显示。
5. 实盘包数为 0 而系统数 > 0 时标红，提示「确认整批清空」。
6. 键盘：Enter 下一行，Tab 下一列，Esc 放弃本行修改。
7. 详情页不分页，一页列出全部行（最多 200 行）。
8. 「只看差异 / 只看未盘」两个筛选按钮。
9. **盘盈一行**：选商品、填实盘包数、填吨数；同一商品不可重复添加（已有行则改该行）。
10. **拆包/半包**：包数只记整数，半包按整包计、吨数手工填实际值。
11. 每次保存写一条 operation_log（含变更行），审计里可查上次实盘值。

### 盲盘的两步

盲盘不允许直接回写：

```
填完 → 点「核对差异」→ 展示差异预览（不写账）→ 确认 → 「回写」
```

差异预览页可返回修改，避免“盲提交”后才发现盘错。

## 6. 差异原因（有差异才填）

四类：录入错误 / 损耗 / 未登记收发 / 其他（需备注）。

- 有差异未选原因，不允许回写；
- 原因为「录入错误」时，行内提供链接跳到关联原单，提示走更正流程（不自动更正）。

## 7. 回写校验（五项）

1. 所有行已录入（含新增盘盈行）；
2. 有差异的行已选原因；
3. 锁仓窗口仍属于本单；
4. 系统库存与快照一致（期间有变动则拒绝，保持进行中，要求重新核对）；
5. 幂等键未使用过。

回写事务：

```
锁盘点单与库存 → 校验五项 → 仅差异行写库存 →
写 stock_journal（盘盈/盘亏，含前后值）→ 写审计与终态 →
释放锁仓 → 提交
```

回写失败（409）后：盘点单保持进行中，页面提示原因，允许重新核对后再次回写。

## 8. 作废

进行中可作废：不改库存、不写流水、保留已录数据、释放锁仓。作废后不能重开，只能新建。

## 9. 锁仓影响

| 操作 | 是否允许 |
|---|---|
| 该仓入库确认 / 出库确认 | ❌ 409，提示盘点单号 |
| 该仓库存调整 / 撤销 | ❌ 409 |
| PDA 扫码、事实补传、冻结 | ✅ 允许 |
| 其他仓库的一切操作 | ✅ 允许 |

## 10. 字段补充

盘点单：mode、scope_json、diff_lines、diff_packages、diff_tonnes。

明细：actual_packages、actual_tonnes（可空=未盘）、diff_packages、diff_tonnes、reason_code、reason_memo、is_extra（盘盈新增行）。

## 11. 接口

GET/POST /api/v1/stocktakes
GET /api/v1/stocktakes/:id
PATCH /api/v1/stocktakes/:id/readings（版本校验）
POST /api/v1/stocktakes/:id/lines（新增盘盈行，唯一性校验）
POST /api/v1/stocktakes/:id/preview（盲盘核对差异，不写账）
POST /api/v1/stocktakes/:id/post（幂等）
POST /api/v1/stocktakes/:id/void
GET /api/v1/stocktakes/:id/export?kind=blank|result

## 12. 明确不做

| 不做 | 原因 |
|---|---|
| 复盘父子单 | 一个人重填即可，审计保留上次值 |
| 待确认状态 | 多一步没意义，录完直接核对回写 |
| PDA 扫码盘点 | 主仓 2,574 包，逐包扫不现实 |
| 按分类范围 | 无分类数据 |
| 差异阈值二次确认 | 标黄提示足够 |
| 刷新快照 | 破坏快照不可变，只能作废重建 |
| 积木打印 | 打印未接入；空白表导出 XLSX 去打印 |

## 13. 验收

1. 建单后同仓入库确认 409，其他仓正常；
2. 建单提示正确显示未确认出库单与待补传数量；
3. 快照不含零库存行；
4. 盲盘：接口不返回系统数；导出空白表不含系统数；核对差异前不显示差异；
5. 盲盘可直接回写被拒绝，必须经核对；
6. 未录完不能回写；有差异未选原因不能回写；
7. 盘盈行重复添加被拒；盘盈行吨数空值被拒；
8. 回写后库存变化 = 差异，流水只在差异行；
9. 重复回写只生效一次；
10. 回写失败后仍为进行中，可重新核对；
11. 作废后库存与流水不变、锁仓释放；
12. 快照后系统库存变动，回写被拒；
13. 吨数折算正确，手工覆盖后以手工值为准；
14. 59 行盘点全流程手工实测 < 5 分钟；
15. 1440/1280 截图。
