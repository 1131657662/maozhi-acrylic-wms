# 库存盘点规范（STOCKTAKE_SPEC）

> 本文档中的状态、类型、结果等库值仅作实现标识；界面显示必须按 docs/UX_STANDARDS.md 映射为中文。

## 1. 定位

盘点就干一件事：**数一遍，把账改对**。不做多余流程。

参照 SAP 实物盘点（建单 → 录入 → 差异过账）与旧 Vue 版字段，按单用户单仓（主仓约 59 行货）的实际规模裁剪。

## 2. 实际操作长什么样

```
① 新建盘点 → 选主仓 → 明盘 → 确定（59 行快照）
② 「导出空白盘点表」→ 打一张纸带去仓库（盲盘时表上不含系统数）
③ 按纸上的商品逐个数包数，写在纸上
④ 回来按行填入实盘包数、核对默认折吨或手填吨数
⑤ 点「只看差异」复核 → 确认回写
```

操作耗时作为后续实测指标，不以示例行数保证实际完成时间。

## 3. 列表页

页头：库存盘点 + [新建盘点]

筛选：仓库、状态（进行中 / 已完成 / 已作废）

列表列：盘点单号、仓库、状态、进度（已盘 42/59）、差异（3 行，盈 1 亏 2）、锁仓时长、创建时间、操作。

行操作：
- 进行中：继续盘点、更多（作废、导出空白表、导出结果）
- 已完成：导出
- 已作废：更多（导出）；详情统一用单号/双击/Enter，不增加行内查看按钮

锁仓时长超过 24 小时标红，提示「盘点未结束，该仓无法确认出入库」。

## 4. 新建盘点

抽屉四项：

| 字段 | 规则 |
|---|---|
| 仓库 | 必填 |
| 范围 | 全部商品（默认）/ 指定商品（多选） |
| 模式 | 明盘（默认）/ 盲盘 |
| 备注 | 选填 |

建单前提示（不阻断）：
- 该仓有 N 张已冻结未确认的出库单 → 「存在未入账作业，需核对实物与快照口径」；冻结不证明已离场，回写前须清单ACK
- 该仓有已登记交接未收齐事实 → 显示登记数/已收数/登记时间；设备实时离线队列「不支持」，未知不得填0，需人工核验

规则：
1. 同仓同时只能有一张进行中盘点；
2. 创建即生成不可变快照并锁仓；
3. 默认全部范围只含正余额库存行（包数 > 0 或吨数 > 0）；指定商品允许生成零快照。此为B6e新增筛选行为，B3a已有库存格默认不作正数过滤；异常负数单列诊断。现场新发现商品走独立盘盈行；
4. 范围确定后不可改；不提供“刷新快照”，快照不对只能作废重建；
5. 本批不扩按分类范围；B6a分类存在后仍按全部/指定商品范围执行。

### 录入规则

1. **包数、吨数独立录入和校验**；吨数默认按「系统吨数 ÷ 系统包数 × 实盘包数」折算，可手工覆盖。按整数克算后四舍五入到100克，保存weight_source=estimated/manual。手工覆盖后改包数不静默重算；显式「恢复默认」才重新折算。
2. 系统包数为0的行（含指定零快照和盘盈行）无法折算，**吨数必填**。
3. 空值 = 未盘，不当作0；仅盲盘estimate_pending表示已填包数、吨数待核算，进度另标「待核吨」，未解析前不能回写。
4. 明盘实时显示差异；盲盘在点「核对差异」后才显示。
5. 实盘包数为 0 而系统数 > 0 时标红，提示「确认整批清空」。
6. 键盘：Enter 下一行，Tab 下一列，Esc 放弃本行修改。
7. 每次渲染最多200行，分页/虚拟窗口不限制整单行数，保留万行能力。草稿按单号+行ID存储，跨页/筛选保留；翻页先保存脏行或保留待保存队列，保存失败不丢输入、不报告全部已保存。并发revision冲突要求重核，不能静默覆盖。
8. 「只看差异 / 只看未盘」两个筛选按钮。
9. **盘盈一行**：选有库存资格商品、独立填包/吨；快照外发现行另存，系统基数为0，禁止INSERT/UPDATE固定快照或移除009触发器。同单仓品在快照与发现行中只能出现一次（锁盘点头检查并约束发现行唯一），已有行则改读数。
10. **拆包/半包**：包数只记整数，半包按整包计、吨数手工填实际值。
11. 每次保存写一条 operation_log（含变更行），审计里可查上次实盘值。

### 盲盘的两步

盲盘不允许直接回写：

```
填完 → 点「核对差异」→ 展示差异预览（不写账）→ 确认 → 「回写」
```

盲盘核对前不返回系统包吨、均重或差异。B6e-1 按用户最新裁定先实行包吨均手填，显式揭示不可撤销；揭示后修改读数仍须重新获取回写预览，但不重新隐藏账面。原待折算、默认折算、发现行及批量保存留后续步骤，不能宣称 B6e-1 已实现。完整版本令牌仍须绑定模式、读数版本、原因、快照及未入账清单。

## 6. 差异原因（有差异才填）

四类：录入错误 / 损耗 / 未登记收发 / 其他（需备注）。

- 有差异未选原因，不允许回写；
- 原因为「录入错误」时可只读查看有证据关联的原单；暂停窗口内禁止更正。若需先改账，显式作废本盘点释放窗口，再完成更正并重建盘点快照；不提供绕过窗口入口。

## 7. 回写校验（保留B3a全部守卫）

1. 所有行已录入（含新增盘盈行）；
2. 有差异的行已选原因；
3. 锁仓窗口仍属于本单；
4. 系统库存与快照一致（真实漂移则拒绝并作废重建，不能仅重新核对放行）；
5. 同幂等键同正文重放原结果（包括完成后重试），异正文409；不得要求幂等键必须未使用；
6. 重新锁读当前未入账清单，存在时必须显式ACK且与预览绑定清单相符；清单变化重新核对；
7. 校验最新revision/previewToken，盲盘须已揭示并确认；包吨独立非负、精度/资格/原因合法。

回写事务：

```
全局库存写锁 → 盘点头 → 未入账相关单据锁 → 同键同正文重放检查 →
锁库存并复验窗口/快照漂移/revision/previewToken/清单ACK/全行包吨 → 仅差异行写库存 →
写 stock_journal（盘盈/盘亏，含前后值）→ 写审计与终态 →
释放锁仓 → 提交
```

回写校验失败（409）整笔回滚，盘点单保持进行中；输入不丢失。清单或录入版本变化可重新核对；库存与固定快照真实漂移不能仅换token放行，须查明原因并作废重建。

## 8. 作废

进行中可作废：不改库存、不写流水、保留已录数据、释放锁仓。作废后不能重开，只能新建。

## 9. 锁仓影响

| 操作 | 是否允许 |
|---|---|
| 该仓入库确认 / 出库确认（含分批发货的每次确认） | ❌ 409，提示盘点单号 |
| 该仓库存调整 / 撤销 / 更正（含数量更正与业务日期更正）/ 转移 | ❌ 409；转移业务未实现 |
| PDA 扫码、事实补传、冻结 | ✅ 允许 |
| 其他仓库的一切操作 | ✅ 允许 |

## 10. 字段补充

新增迁移职责M-STOCKTAKE-EXTENSIONS：头部mode、readings_revision；原readings扩reason_code/reason_memo、weight_source、half_package、estimate_pending（盲盘待折算）；沿用原独立actual包/克字段。新stocktake_extra_lines引用盘点头及商品，保存发现时间/人、独立包克与原因；不可变快照表不增删行。差异/进度为投影，不并行维护另一套事实。核对令牌绑定版本及清单；所有新增业务数据非空时拒绝破坏性down。

## 13. 验收

1. 建单后同仓入库确认 409，其他仓正常；
2. 提示未确认单与已登记交接未收齐数，离场/设备实时队列显示不支持，不推断为0；
3. 默认正余额范围与指定商品零快照分别验证；新增盘盈不改变原快照指纹；
4. 盲盘录入接口不返回系统数/均重/差异；空白导出不含系统数；核对后才返回系统数、默认折算值和差异；
5. 盲盘可直接回写被拒绝，必须经核对；
6. 未录完不能回写；有差异未选原因不能回写；
7. 盘盈行重复添加被拒；盘盈行吨数空值被拒；
8. 回写后库存变化 = 差异，流水只在差异行；
9. 重复回写只生效一次；
10. 回写失败仍进行中且库不变；同键重放、异正文409、ACK过期、漂移、并发保存与回写分别给输出；
11. 作废后库存与流水不变、锁仓释放；
12. 快照后系统库存变动，回写被拒；
13. 折算、四舍五入、零基数、半包及只改包数分别验证；手工覆盖后以手工值为准；万行分页/筛选返回后已填数据不丢失，每次渲染≤200；
