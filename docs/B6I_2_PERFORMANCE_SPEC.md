## 测量

`scripts/b6i2/measure.ts baseline|after`，生产 Web 构建，本地随机 `maozhi_test_*`，固定合成数据：每类 10000 主单 / 100000 有效明细，反查 WL-P000130，50 行；周转 10000 流水 / 50 仓品，2026-06-01 至 2026-11-14，固定 asOf。

改前/后各组 30 次；反查由首次查询后点击第 5 页至 50 行更新和两次 rAF；周转导航至业务数据行、图表和两次 rAF。nearest-rank p95 取第 29/30 个；独立 profile 不计入样本。记录接口、逐 SQL await 墙钟、响应字节、CDP 脚本/布局/样式耗时、CPU profile、主机负载。SQL await 包括引擎/传输/解码，不等于数据库纯 CPU。

冷组使用全新浏览器 context（无 HTTP/React Query 缓存）；热组复用 context 并重新导航，页面查询仍执行。MySQL buffer pool 不清，造数可能暖库；不声称物理冷盘。若新增跨请求服务端缓存，冷组须显式隔离/清空该缓存。主机负载/构建模式差异单列，保留所有有效慢样本。

结果保存规范化内容与 SHA-256：只剔除请求 token 等身份字段，所有业务行、汇总、周转值和顺序必须一致。EXPLAIN 使用相同 SQL/参数；服务器 slow_query_log 配置只读，慢查询证据为验证进程逐条探针。

目标为实测反查翻页 p95 ≤500ms、周转冷首屏 ≤800ms，不能通过改变断言、分页默认值、减少业务结果或更换数据口径达成。
