## 3. 缺口清单（按优先级）

### P0 本轮必须做

| 项 | 说明 |
|---|---|
| 行点击选中 | 单击切换、双击打开、链接与按钮不误触 |
| 宽屏手柄 | 去掉“必须溢出”条件 |
| 拖拽流畅 | 拖动期改 DOM，松手提交 |
| 排序即时反馈 | 箭头立即变、保留旧数据、表头 loading |
| 错误文案 | 分类中文 + 动作 + 折叠详情 |
| 界面用词 | 清除开发术语与英文库值 |

### P1 下一批

| 项 | 说明 | 价值 |
|---|---|---|
| 联想搜索（B6g） | 商品/客户/供应商/仓库/车辆/单据号 | 高，减少输入错误 |
| 密度切换 | 紧凑/标准，恢复 ProTable 的 density | 中，单屏多看几行 |
| 固定列确认 | 单号左固定、操作右固定 | 中，横向滚动时不迷路 |
| 列宽自适应 | 双击手柄 = 按内容自适应，而不是只回默认 | 中 |
| 单元格复制 | 右键或悬浮复制单号/编码 | 中，沟通常用 |
| 表头吸顶 | 滚动到 40 行后仍能看到列名 | 中，长列表必备 |
| 批量结果提示 | 全部成功/部分成功/全部失败分别提示，可逆给撤销入口 | 中 |

### P2 可选

| 项 | 说明 | 判断 |
|---|---|---|
| 多列排序 | Shift+点击第二列 | 数据量小，收益有限 |
| 列头筛选 | 每列漏斗 | 与现有查询抽屉重叠，可能重复 |
| 键盘导航 | j/k 移动、x 选中 | 仓管多用鼠标，优先级低 |
| 右键菜单 | 复制/打开/撤销 | 与「更多」重叠 |
| 虚拟滚动 | 万行渲染 | 分页 50，不需要 |

## 4. 明确不做

| 不做 | 原因 |
|---|---|
| 无限滚动 | 分页更利于对账与定位 |
| 行内编辑 | 单据必须走确认链路，不能就地改 |
| 协作光标/评论 | 单用户 |
| 拖拽行排序（业务数据） | 排序是查询能力，不是持久顺序 |
| 表格转置/透视 | 导出到 Excel 做 |

## 5. 批次安排

| 批次 | 内容 |
|---|---|

## 6. 验收指标

| 指标 | 目标 |
|---|---|
| 单击行到选中高亮 | < 50ms |
| 拖拽列宽到视觉变化 | 每帧生效（< 16ms） |
| 排序点击到箭头变化 | 立即 |
| 排序请求 p95 | < 300ms（本地）、< 800ms（10 万行） |
| 联想搜索 p95 | < 150ms |
| 错误文案 | 页面搜索不到英文异常与状态码 |
| 界面用词 | 禁止词命中数 0 |

## 7. 第二轮对标：现代产品还做了什么

| 能力 | SAP / NetSuite | 主流 SaaS（Linear / Notion / Stripe） | 我们的判断 |
|---|---|---|---|
| 命令面板（Cmd+K） | 无 | ✅ 核心入口 | **建议做**，14 个页面 + 大量单据，跳转最快的方式 |
| 行快速预览（侧滑 peek） | 部分 | ✅ 不离开列表看详情 | **建议做**，减少「打开详情再返回」 |
| 未保存离开提醒 | ✅ | ✅ | **必须做**，防误关丢数据 |
| 列头菜单（排序/固定/隐藏/自适应） | ✅ | ✅ | 建议做，把列宽三项合成一个入口 |
| 滚动位置恢复 | 部分 | ✅ | 建议做，从详情返回列表停在原处 |
| 千分位与 tooltip | ✅ | ✅ | 建议做，长数字与截断文本可读 |
| 快捷键面板（?） | ✅ | ✅ | 可选，与命令面板合并 |
| 暗色模式 | 部分 | ✅ | 不做，仓库强光环境用不上 |
| AI 助手 / 智能建议 | 新增 | 宣传点 | 不做，当前数据量不需要 |
| 协作光标 / 评论 | ✅ | ✅ | 不做，单用户 |
| 过渡动画 | 克制 | 大量 | 不做，操作频繁的界面动画是负担 |

### 7.1 建议新增的四项

| # | 项 | 说明 | 优先级 |
|---|---|---|---|
| 1 | 命令面板 | `Ctrl+K` 搜单号、客户、商品、页面；回车直达 | P1 |
| 2 | 行快速预览 | 双击右侧滑出详情摘要，底部「打开完整详情」 | P1 |
| 3 | 未保存离开确认 | 表单有改动时关闭/跳转二次确认；草稿存本地 | **P0** |
| 4 | 滚动位置恢复 | 从详情返回列表，回到离开时的行与位置 | P1 |

### 7.2 明确不做

| 不做 | 原因 |
|---|---|
| 暗色模式 | 仓库强光环境下无价值，维护两套主题成本高 |
| AI 建议/自动填单 | 数据量与场景不需要，且不可解释 |
| 协作与评论 | 单用户 |
| 大面积动效 | 每天看 8 小时的界面，动画只会拖慢操作 |
| 无限滚动 | 分页更利于对账定位 |
